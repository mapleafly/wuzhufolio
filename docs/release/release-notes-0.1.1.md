# WuZhuFolio 0.1.1

补丁版：修复 0.1.0 发布后人工验收发现的问题，并加入一项人工批准的增量。
**数据格式与 0.1.0 完全兼容**（数据库 schema 未变、`.cpro` 备份格式未变），可直接覆盖安装，数据目录不变。

> ## 📦 本版发布范围与重要说明
>
> **支持平台**：**Windows 10/11 (x64)** 与 **Linux (x64)**。
>
> **macOS 不提供发行包**——macOS 应用在商店外分发需要 Developer ID 代码签名与 Apple 公证（否则会被 Gatekeeper 拦截），
> 本项目当前不采购签名证书。需要 macOS 版的用户可以 **clone 仓库自行编译**（需 macOS + JDK 17，步骤见《用户指南》§3 ②）；
> 自编译产物同样未签名，首次打开需**右键 → 「打开」**放行。
>
> **⚠️ 本版产物未做代码签名**（Windows / Linux 均未签名，这是本项目的既定选择，非疏漏）：
> Windows 首次下载/运行时 SmartScreen 可能提示「Windows 已保护你的电脑 · 未知发布者」——请点「**更多信息**」→「**仍要运行**」。
>
> **完整性校验**：下载后请用本页附件的 `SHA256SUMS` 核对。
> Windows：`certutil -hashfile <文件名> SHA256`；Linux：`sha256sum -c SHA256SUMS`。
>
> **数据与隐私**：全部数据只存本机（`%USERPROFILE%\.wuzhufolio` / `~/.wuzhufolio`），整库 AES-256 加密；**零遥测**；
> 出站连接仅三个白名单主机（CoinGecko / CoinMarketCap / Binance）。详见《用户指南》。
>
> **安装提示**：安装或解压路径请使用**纯英文（ASCII）**目录。

## 修复

- **侧边栏不再出现「组件走查」页**：该页是开发用的界面组件预览，0.1.0 误随正式版发布；本版改为构建期开关，正式版不含该入口，键盘焦点顺序同步移除。
- **Linux 托盘图标显示不全**：修好了图标只露出左上角一块的问题（根因是高分屏下图标被二次缩放后按原尺寸画进托盘窗口；现按平台策略出图）。
- **托盘菜单缺「刷新行情」且点「立即同步」像没反应**：新增「**立即刷新行情**」（与「立即同步交易」分列，两类接口相互独立）；点选后**立即显示开始提示、完成后显示结果**——此前 Linux 上点「立即同步」其实已在同步，只是系统气泡不显示，看起来像没反应。
- **托盘「打开主界面」不把窗口提到最前**：窗口被别的窗口遮挡时，点击后现在会置前并取得焦点。
- **币种搜索排序与条数**：改为「相关性 → 有效币种 → **市值排名** → 符号」排序，并在交易/资金/校准/行情四处统一为**最多 20 条、可滚动、行内含币种标识**。此前只按字母序，搜索 `usdt` 时真正的 Tether 被同名小币挤到第 42 位（`btc` 第一条甚至不是比特币）。
- **Linux 应用图标显示为通用齿轮**：主窗口补上应用图标；`.deb` 安装后应用图标进入系统图标主题（8 档尺寸）、桌面条目补 `StartupWMClass` 与正确分类，并在安装时刷新图标缓存。Windows 侧同轮补上窗口/任务栏图标（此前为 Java 默认图标）。
- 清理两处冗余空安全调用（编译警告归零）。

## 变更

- **成交币自动进入「行情」自选**：手动记录/编辑交易、CSV 导入、交易所同步涉及的币种会自动加入行情自选，随后续刷新更新行情；**手动移除后再次交易会重新加回**；**取消自选数量上限**（原 50 条）。
- 行情自选与交易/资金/校准三处的候选列表统一为同一组件与同一条数上限（20 条，均可滚动）。

## 安全

- 无变更：本轮未触及加密、密钥、备份格式与出站白名单；自选维护失败不影响交易落账。
