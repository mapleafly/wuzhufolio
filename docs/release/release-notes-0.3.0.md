# WuZhuFolio 0.3.0

**多账户看得清 + 空账户第一次有数**（里程碑 M15「B 迭代 · 桌面端体验深化」）。本版把「我现在在哪个账户」放到**顶栏常驻**，
给**空账户**补上「一键加载示例数据」的首次引导，并支持把**其它账户的自选清单**经显式选择 + 二次确认**一次性复制**到当前账户；
同时把设置页的同步入口纳入统一会话门禁。
**数据格式与 0.2.0 完全兼容**（数据库 schema 未变（仍为 12）、`.cpro` 备份格式未变），可直接覆盖安装，数据目录不变。

> ## 📦 本版发布范围与重要说明
>
> **支持平台**：**Windows 10/11 (x64)** 与 **Linux (x64)**（`.deb` / `.rpm` / `.AppImage` / 便携版）。

> 自编译产物同样未签名，首次打开需**右键 → 「打开」**放行。
>
> **⚠️ 本版产物未做代码签名**（Windows / Linux 均未签名，这是本项目的既定选择，非疏漏）：
> Windows 首次下载/运行时 SmartScreen 可能提示「Windows 已保护你的电脑 · 未知发布者」——请点「**更多信息**」→「**仍要运行**」。
>
> **完整性校验**：下载后请用本页附件的 `SHA256SUMS` 核对。

> **数据与隐私**：全部数据只存本机（`%USERPROFILE%\.wuzhufolio` / `~/.wuzhufolio`），整库 AES-256 加密；**零遥测**；
> 出站连接仅三个白名单主机（CoinGecko / CoinMarketCap / Binance）。本版新增的**示例数据只在本机生成、不联网**；
> **不内置检查更新**——想知道有没有新版本，请自行查看本页（**GitHub Releases 是唯一下载渠道**）。

## ⚠️ 升级须知（从 0.2.0 升到 0.3.0 请先读）

| 变化 | 你需要知道的 |
|---|---|
| **自选清单仍是「账户级」**（D41 延续） | 每个账户的自选独立、账户之间互不可见；「交易过的币自动加入自选」也只影响当前账户。若你是从 **0.1.1 或更早**直接升到本版：旧版那份**全局自选清单**会由**升级后首次访问行情页（读取自选）的账户**一次性认领，其它账户从默认种子（仅 USDT）开始；认领只发生一次，旧全局行按只读保留（不删除）。从 0.2.0 升上来通常已认领完成，无需额外动作。 |
| **示例数据：显式标记 + 可清除**（新功能，仅空账户） | 「交易管理」页空态可一键「**加载示例数据**」；示例记录的备注以 **`[示例]`** 开头、页面常驻「示例数据」标识条，「**清除示例数据**」需二次确认且**只删标记行**——你自己的记录一条都不会动。示例数据**只在本机生成、不联网**。若你在示例数据之上直接记了自己的真实买入，程序会**保留**被真实记录依赖的那笔示例增资并提示（避免你的记录变成负持仓）。 |
| **跨账户导入 = 显式一次性复制**（新功能） | 行情页「**从其它账户导入…**」需**显式选择来源账户 + 二次确认**（确认前会显示「将从账户「X」导入 N 个币种」）；只复制**自选清单**，交易 / 资金流水 / API 密钥**一概不动**，**来源账户一字不改**，导入是单向的、可随时移除。本版**不提供**隐式跨账户可见或「所有账户聚合」视图。 |

**数据安全**：数据库结构与备份格式**未变**（schema 仍为 12、`.cpro` 格式未变），升级不会丢数据；
0.2.0 与 0.3.0 的 `.cpro` 备份**可互导**。如需回退到 0.2.0，见《回滚方案》**§4.1.2**——降级后只是少了本版的新入口与标识
（`[示例]` 前缀行在 0.2.0 作为普通备注展示），**数据不丢**。用户侧操作细节见《用户指南》**§3.5**。

## 亮点

- **任何页面都知道自己在哪个账户**：顶栏常驻「账户 · <账户名>」，切换账户弹窗标注「当前账户：X」。
- **新账户不再是一片「--」**：空账户一键加载示例数据，交易与资金流水立刻有数、看板立刻出现这组持仓（净值按可得币价折算），且**显式标记、可一键清除**。
- **换账户不用重新挑币**：行情页「从其它账户导入…」把自选清单显式复制过来，**来源账户一字不改**。

## 新增

- **多账户可见性**（D45）：顶栏常驻「**账户 · <账户名>**」（`topbar-account`，账户名为空时不渲染）；切换账户弹窗新增
  「**当前账户：X**」一行，与标题「切换到账户「Y」」形成对照，避免「以为在看 A 账户、其实在 B 账户」。
- **示例数据与首次引导**（D46）：空账户的「交易管理」页空态新增引导与「**加载示例数据**」按钮——一键写入
  **1 笔增资 100,000 USDT + 3 笔买入（BTC / ETH / SOL）+ 1 笔卖出**；加载后交易、资金与看板**立即出现这组记录与持仓**
  （**累计增资 100,000** 与**已实现盈亏 +1,983.00** 由账本推导、**与行情无关**；**净值与 ROI 按当时可得的币价折算**，
  会随行情变化——示例数据集自带的价格口径为 **净值 109,952.50 / ROI +9.95%**，宣传素材即按该口径渲染）。
  示例行以 `notes` 行首 **`[示例] `** 显式标记，页面常驻「示例数据」标识条；清除走**二次确认**且**只删标记行**。
  **只在空账户可加载**：账户已有你自己的交易或资金记录时点它会提示「当前账户已有真实记录：示例数据只能加载到空账户」，
  **不会写入任何内容**；重复点击幂等。
- **自选清单跨账户导入**（D48，**C2**，mini 闭环）：行情页命令区新增「**从其它账户导入…**」（仅当本机存在其它账户时显示）——
  在弹窗里**选择来源账户**（每行显示该账户的自选数量与币种）→ **下一步**核对摘要 → **确认导入**，把来源账户的自选清单
  **一次性复制**到当前账户（保序去重；全为新增 / 有重复 / 未做改动 / 来源为空各有明确文案）。
  **只复制自选清单**，交易记录、资金流水、API 密钥一概不动；**来源账户的数据完全不变**（含不触发其一次性认领）；
  不提供隐式跨账户可见或聚合视图。

## 变更

- **设置页同步入口需登录**（D44）：设置 → 「API 管理」里未登录点「**立即同步**」会提示「请先登录」，**不进入任何同步路径**
  （页面级入口改经与托盘 / 顶栏同一个门禁，行级入口前置判定）；此前该入口会绕过门禁并给出归因错误的失败提示。

## 修复（用户可感的稳定性影响）

- **时间敏感用例不再「到点必红」**（DEF-58）：币种详情「时间」筛选的 UI 用例把交易时间硬编码为固定时刻，而产品按**真实时钟**
  筛选 ⇒ 自 **2026-10-10** 起该用例**永久失败**（与当轮业务改动无关）。已改为按当前时刻构造**相对**时间；
  预防条款写入 `AGENTS.md §7.3-8`（时间敏感断言必须相对时间或注入 `Clock`）⇒ **质量门的绿灯重新可信**。
- **CI 不再偶发红**（DEF-59）：慢机环境下「登出 → 回登录页」的 UI 等待超时过短 ⇒ 偶发失败（Windows 作业单点红）。
  已把该用例的默认等待放宽到 ≥10 s（实测取 15 s）并在点击前先等目标节点 ⇒ 不让「环境慢」冒充版本缺陷。
- **视觉回归门禁不再误报**（DEF-60）：本版新增的「视觉回归 24 张」计数断言在 Gradle **构建缓存命中**
  （测试不执行、副产物不产出）时**三平台全红**。已把视觉回归产物声明为测试任务的**输出目录**（缓存命中时连同产物一起恢复）
  ⇒ 同一提交在「测试真跑」与「缓存恢复」两条路径下均绿，发布件不会因缓存路径被误判。

## 工程

- **视觉回归进 CI**（D47）：每次 CI 由测试**真实渲染 24 张**（4 页面 × 2 主题 × 3 尺寸）并归档，基线比对为**报告型不阻断**
  （实测差异集中在文字边缘、占比均 <1.2%，属跨平台光栅化差异）；产物计数已收紧为**断言**。
- **打包冒烟收敛为门禁**（D47）：Windows app-image 常规路径冒烟**转阻断式**，非 ASCII 路径变体保持信息性，MSI 维持观察期。
- **测试素材写回受门控**（D47 / F6）：全量构建**不再改写仓库内的发布素材**（默认落构建目录，显式开关才写回仓库），
  发布素材与发布影片保持一一对应。
- **影片素材与影片随本版一并重生成**：4 张影片 UI 素材的数值真源已由「测试内手写的黄金数值夹具」改为**产品自身的示例数据集**
  （画面 = 用户点「加载示例数据」后真实看到的界面），`docs/release/promo/assets/ui/` 素材与宣传影片按
  `promo/README.md` 复现管线**一并**重生成（**不得单独替换素材或影片**）。
- **三条工程规约入 `AGENTS.md §7.3`**（D47）：临时埋点卫生（标注清理条件 + 收尾轮逐条清理）、
  收尾轮状态对齐 checklist（9 项回扫）、时间敏感断言规范。

## 安全

- **无削弱**：未触及加密、密钥派生、备份格式与出站白名单；schema 仍为 12、`.cpro` 备份格式未变（跨版本可互导）。
- **收紧**：设置页同步入口补齐会话门禁 ⇒ 四条手动同步入口（托盘 / 顶栏 / 设置页页面级 / 设置页行级）口径统一。
- **示例数据零网络**：由本机数据集生成、只写本地库，随账户隔离与 `.cpro` 备份（标记随 `notes` 原样往返，恢复后仍可识别与清除）。
- **跨账户导入为显式且可审计的单向复制**：只写当前账户的自选清单，来源账户逐字节不变，不引入隐式跨账户可见性。
