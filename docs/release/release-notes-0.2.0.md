# WuZhuFolio 0.2.0

**界面体系统一 + 使用反馈收口**（里程碑 M14）。本版把界面全面统一到 **Material 3 视觉规范**，
修完 0.1.1 反馈的全部问题，并收口两条产品口径（登录前不联网刷新行情、自选清单改账户级）。
**数据格式与 0.1.1 完全兼容**（数据库 schema 未变、`.cpro` 备份格式未变），可直接覆盖安装，数据目录不变。

> ## 📦 本版发布范围与重要说明
>
> **支持平台**：**Windows 10/11 (x64)** 与 **Linux (x64)**。
>
> **macOS 不提供发行包**——macOS 应用在商店外分发需要 Developer ID 代码签名与 Apple 公证（否则会被 Gatekeeper 拦截），
> 本项目当前不采购签名证书。需要 macOS 版的用户可以 **clone 仓库自行编译**（需 macOS + JDK 17，步骤见《用户指南》§3 ②）；
> 自编译产物同样未签名，首次打开需**右键 → 「打开」**放行。
>
> **⚠️ 本版产物未做代码签名**（Windows / Linux 均未签名，这是本项目的既定选择，非疏漏）：
> Windows 首次下载/运行时 SmartScreen 可能提示「Windows 已保护你的电脑 · 未知发布者」——请点「**更多信息**」→「**仍要运行**」。
>
> **完整性校验**：下载后请用本页附件的 `SHA256SUMS` 核对。
> Windows：`certutil -hashfile <文件名> SHA256`；Linux：`sha256sum -c SHA256SUMS`。
>
> **数据与隐私**：全部数据只存本机（`%USERPROFILE%\.wuzhufolio` / `~/.wuzhufolio`），整库 AES-256 加密；**零遥测**；
> 出站连接仅三个白名单主机（CoinGecko / CoinMarketCap / Binance）。
> **本版起：未登录时不会发出任何行情请求**（详见下方「变更」）。
>
> **安装提示**：安装或解压路径请使用**纯英文（ASCII）**目录。

## ⚠️ 升级须知（从 0.1.1 升到 0.2.0 请先读）

| 变化 | 你需要知道的 |
|---|---|
| **行情刷新需要先登录** | 未登录时应用不再联网刷新行情（启动与后台循环都跳过）；点托盘「立即刷新行情」会提示「请先登录」。登录后会自动立即刷新一次。 |
| **交易同步需要先登录** | 交易所 API 密钥属于**账户**，未登录没有可同步的账户 ⇒ 点托盘「立即同步交易」会提示「请先登录」（此前误报「没有可同步的密钥」）。 |
| **自选清单改为账户级** | 每个账户有独立自选，账户间互不可见；「交易过的币自动加入自选」也只影响当前账户。**升级后第一个登录的账户会继承旧版那份全局自选**（仅一次），其他账户从默认种子（仅 USDT）开始。 |
| **界面观感更新** | 配色、字号层级、圆角、动效统一到 Material 3；功能位置与操作方式不变。 |

**数据安全**：数据库结构与备份格式**未变**，升级不会丢数据；如需回退到 0.1.1，见《回滚方案》§4。

## 变更

- **界面全面采用 Material 3 视觉规范**：配色由品牌种子色经 Google 官方算法生成完整 M3 色板（明/暗双主题、全部语义 role）；
  字体层级改为 M3 15 档；圆角统一 4/8/12/16/28；动效采用 M3 时长与缓动 token。
  这是 0.1.1 反馈「组件像手工制作」的根治——此前设计基准与官方组件观感冲突，导致只能手绘；现一律以官方组件为底、token 统一。
- **登录前不发行情刷新请求**（隐私口径收紧）：启动首刷 / 后台周期刷新 / 手动「立即刷新行情」三处统一以「会话已解锁」为前提；
  未登录时**零行情请求**。
- **托盘「立即同步交易」同样要求登录**：交易所密钥归属账户，未登录没有可同步的主体；未登录点击只提示「请先登录」，
  且顶栏同步入口改为经统一门禁执行（三条入口一致）。
- **自选清单改为账户级**（账户隔离）：此前自选存在全局设置里，会导致「B 账户能看到 A 账户交易过的币」；
  现每个账户独立且有序，未登录不展示任何自选。
- **Linux 托盘改为系统原生菜单**：改用桌面原生协议（StatusNotifierItem + dbusmenu），菜单由桌面系统渲染，中文与观感与系统一致；
  左键打开主界面、右键四项菜单（打开主界面 / 立即同步交易 / 立即刷新行情 / 退出），与 Windows / macOS 动作一致；不支持时自动回退内置菜单。
- **组件继续向 M3 收口**：下拉选择触发框改用官方 M3 描边按钮；轻提示对齐 M3 Snackbar 的配色与形状规范。

## 修复

- **弹窗内输入空格/回车不再关闭弹窗**（影响面最大）：此前在**任意弹窗的输入框里敲空格都会把弹窗关掉**；现已修复（含认证弹层）。
- **金额/数量输入对复制粘贴健壮**：`¥1,234.56`、全角数字、不换行空格等不再导致「算不出总价 / 报价格无效」；
  对 `1.234,56` 这类语义歧义格式明确报错而不猜测（避免静默 100 倍误差）。
- **托盘菜单可点选**：修好「菜单看得见、点不到 / 点哪都开主窗口」；菜单按系统坐标精确定位并夹取到屏幕内，改为鼠标释放时弹出，新增键盘操作（↑/↓/Enter/Esc）。
- **Linux 托盘图标显示不全**：修好图标只露左上角一块的问题（0.1.1 已修，本版沿用）。

## 安全

- 无削弱：未触及加密、密钥派生、备份格式与出站白名单；
- **收紧**：未登录时不再产生行情外联（本地化/零遥测口径的进一步落实）；自选改为账户级，消除跨账户可见性。
