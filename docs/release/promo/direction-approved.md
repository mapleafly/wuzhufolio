## 2. 三方向方向板（真实渲出，非文字描述）

| 方向 | 名称 | 气质定位 | 运动语言 | 参照 | 方向板 |
|------|------|----------|----------|------|--------|
| **A** | 账簿 The Ledger | 「像一本摊在书桌上的私人账册」 | 缓慢推近 + 翻页式揭示，节奏沉稳、无弹跳 | Stripe Press 的书感排版 / 無印良品的留白秩序 | `boards/direction-a.png` · `direction-a.html` |
| **B** | 暗夜金库 Vault Noir | 「夜里一间安静的金库，光从数据里来」 | 缓入推轨（dolly-in）+ 掠光扫过界面，节奏低沉 | Ash Thorp 暖色赛博影像 / Apple 产品特写运镜 | `boards/direction-b.png` · `direction-b.html` |
| **C** | 本地机器 Local Machine | 「一份可以逐行核对的规格书」 | 网格对齐的机械式位移与图层展开，精确无过冲 | Teenage Engineering 工业排版 / IBM Design Language | `boards/direction-c.png` · `direction-c.html` |

**三方向的差异维度**（不是换色板，而是三套视觉逻辑）：

- **A** 走**暖纸浅色 + 印刷质感**，把 UI 当作「贴在账册上的一页」，情绪是私密与克制；
- **B** 走**暖色暗场 + 体积光**，把 UI 当作「金库里的发光体」，情绪是安全与精密（明确避开「深蓝底 + 青紫霓虹」的 AI slop 偷懒解）；
- **C** 走**冷白工程图纸 + 剖面图**，把「数据不出设备」做成图层与边界的技术表达，情绪是透明与可验证。

**共同约束（三版一致）**：色板全部取自产品真实设计 token（P1 原型明/暗主题），不发明新色；不使用 emoji 作图标；不做「圆角卡片 + 左侧彩条」；不编造统计数字；UI 一律用真实截图。
