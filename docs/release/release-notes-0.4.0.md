# WuZhuFolio 0.4.0 发布说明（**草稿 · 未发布**）

> **状态**：**开发中草稿**（迭代 `M16`）。正式发布说明将在 **0.4.0 发布准备**时定稿（与 `CHANGELOG.md` 的 `[0.4.0]` 段同步）。
> **版本号**：`0.4.0`（minor）· **相关决策**：`D50`（迭代范围 · C1）· `D51`（macOS 进发布范围 · C1，反转 2026-09-22 与 2026-10-13 口径）· `D52`（`D41` 改「不认领」· C2，`amends D41`）

---

## 行为变更

> **自选清单的迁移行为变更**：0.4.0 起，**升级后不再自动把旧版全局自选清单认领给第一个访问行情页的账户**（`D52`）。
> 旧清单**仍保留在你的本地数据库中（不会被删除）**，但不再展示；如需继续使用，请在**行情页重新添加**（或从你自己的备份恢复）。
> **多账户用户尤其注意**：此前该行为可能把旧清单给了**非**原主账户。
> 旧 `.cpro` 备份仍可正常恢复；本次变更**不删除数据、不改数据库结构、不改备份格式**。
