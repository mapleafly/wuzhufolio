## 1. 签名到底解决什么、不解决什么

| 签名能解决 | 签名**不能**解决 |
|------------|------------------|
| 让 Windows/macOS **识别发布者身份**，用户看到的不再是「未知发布者」 | 不能让杀毒软件**永不误报**（误报仍可能发生，可申诉） |
| 让用户能**验证「这个安装包确实来自该项目、且未被篡改」**（配合 SHA256 校验） | 不能替代**代码质量与隐私合规** |
| **持续签名可累积发布者信誉**，SmartScreen 提示随版本发布逐步消失 | 不能**一次性**立刻消除 SmartScreen（见 §2 的 2024 变更） |
| macOS 上**解除 Gatekeeper 拦截**（配合公证），这是商店外分发的硬门槛 | 不能绕过 macOS 公证要求（未公证照样被拦） |

**重要变化（2024 起，微软官方口径）**：**EV 证书不再「首次下载即免 SmartScreen」**——EV 与 OV 现在走**同一套信誉累积机制**。
因此「多花一倍钱买 EV 换即时免提示」这条路**已经不成立**。

**硬件令牌要求（CA/Browser Forum，2023 年 6 月起）**：OV/EV 证书的私钥**必须存放在硬件安全模块（HSM）或硬件令牌**上。
这条规定直接改变了 CI 的签名方式——**私钥不能再以 `.pfx` 文件形式塞进 GitHub Secrets 在云端 runner 上签名**（这也是本项目 `signing-notarization.md §3.2` 里那条 `signtool /f cert.pfx` 流水线**在买到证书后必须同步改造**的原因）。

## 2. Windows 五条路径详解

### ① SignPath Foundation —— **开源项目免费签名**（推荐先评估）

- **是什么**：SignPath 基金会为符合条件的开源项目**免费提供代码签名**（OV 级），私钥存放在**他们的 HSM** 上，签名走他们的托管流水线，与 GitHub Actions 集成简单。微软官方文档也把它列为 OSS 的免费选项。
- **代价（必须先看清楚）**：证书签发给的是 **SignPath Foundation 本身**，也就是说 —— **用户看到的发布者是「SignPath Foundation」，不是「WuZhuFolio」**。基金会用**自己的名义为「这个二进制确实由你的仓库构建」背书**。
- **申请条件**（官方条款摘要）：
  - 使用 **OSI 认可的开源许可证**，且无商业双许可 → **本项目 AGPL-3.0 ✅ 符合**
  - 不含专有/闭源组件（系统库除外）→ ✅
  - 无恶意软件、尊重用户隐私与安全（隐私条款要求明确披露数据行为）→ ✅（本项目零遥测，是加分项）
  - **项目处于活跃维护状态** → ✅
  - **项目已经以待签名的形态发布过** → ⚠️ **这一条对本项目正好合适**：先发未签名 0.1.0，就有了「已发布的形态」
  - 功能需在下载页/商店页有文档说明 → ✅（已有用户指南）
  - 只能签自己的项目与自己的二进制 → ✅
- **成本**：0 元。**周期**：提交申请后由基金会审核（含人工沟通），通常以周计。
- **适合谁**：纯开源项目、能接受「签名发布者 = 基金会」。
- **需要做什么**：官网申请 → 通过后在其平台配置签名流水线 → CI 里改为调用其签名 API/客户端。

### ② OV 证书 + 云签名服务 —— 想要「发布者 = 自己」时的方案

- **证书**：CA（DigiCert / Sectigo / GlobalSign / SSL.com 等）签发的 Organization Validated 代码签名证书，**约 $150–300/年**，全球可用（中国大陆个人开发者也可购买，需实名/身份核验，通常数个工作日）。
- **硬件令牌**：新证书私钥按规范放在 USB 令牌或云 HSM 上。
  - **USB 令牌**：插在你自己的机器上 → **云端 GitHub runner 用不了**，只能配**自托管 runner**（把 GitHub Actions 跑到你这台插着令牌的机器上），或**改为本地手动签名**。
  - **云签名服务**（无需令牌、CI 友好）：例如 **SSL.com eSigner**（官网实测价：证书 **$129 / $349 / $359 每年**分档 + 云端签名 **Tier 1 约 $15/月** 起）；DigiCert KeyLocker、Sectigo 亦提供同类服务。这一类是**云端 CI 签名的正解**。
- **合计成本估算**：约 **$300–500/年（≈ ￥2,200–3,700/年）**。
- **适合谁**：需要企业级信任语境、或不能接受「发布者是基金会」。
- **本项目影响面**：买证书后需改造 `signing-notarization.md §3.2` 的流水线（`.pfx` → 云签名 API 或自托管 runner）。

### ③ EV 证书 —— **不建议购买**

- 价格 **$400+/年**（约 ￥2,900+），身份核验更严（部分 CA 要求企业实体）。
- **自 2024 年起不再提供「首次下载免 SmartScreen」**，与 OV 效果相同。
- 唯一仍有价值的场景：**企业采购流程**明确要求 EV（本项目不涉及）。
- 结论：**除非将来为了某个企业分发场景，否则不要买**。

### ④ Azure 受信任签名 / Azure Artifact Signing —— **本项目不可用（地区限制）**

- 微软自家的云签名服务：**约 $9.99/月**，**不需要硬件令牌**，与 CI/CD 集成最好（是微软文档里对非商店分发的首推）。
- **但地区受限**：组织仅限 **美国 / 加拿大 / 欧盟 / 英国**；**个人开发者仅限美国 / 加拿大**。
- → **中国大陆的个人开发者无法使用**。这条排除掉之后，「便宜 + CI 友好」的组合就只剩「SignPath Foundation（免费）」或「OV + 云签名（付费）」。

### ⑤ 上架 Microsoft Store（MSIX）—— 免费的另一种免提示路径（备选）

- **微软代签**：以 MSIX 包上架商店时，**微软会对包重新签名**，用户安装**不会看到 SmartScreen 警告，也不需要你买任何证书**。
- **代价**：需要做 **MSIX 打包**；本项目当前技术栈（jpackage 17）**不产出 MSIX**（本机 `jpackage --help` 实测：Linux 下合法类型仅 `app-image / rpm / deb`；Windows 下为 `app-image / exe / msi`），需要额外用 MSIX Packaging Tool / `makeappx` 把现有安装包转成 MSIX，并处理沙箱下的数据目录重定向（本项目数据写在 `%USERPROFILE%\.wuzhufolio`，与 MSIX 容器化行为需实测）。
- **定位**：可作为**并行的分发渠道**（不是 GitHub Releases 的替代），工程量独立、可后置。

## 3. macOS：Apple Developer Program

- **必须买吗**：只要你想让 macOS 用户**双击就能打开**，就必须 —— 商店外分发的 macOS 应用需要 **Developer ID 签名 + Apple 公证**，否则 Gatekeeper 拦截（用户得右键「打开」才能绕过，体验很差）。
- **价格**：**99 USD / 会员年**（按地区以本币计费）。
- **个人注册（适合本项目维护者）**：需要一个开启双重认证的 Apple Account、达到法定年龄、**填写与证件一致的法定姓名**（不能用昵称/公司名，否则会延迟审核）；过程中核验**法定姓名、邮箱、电话、地址**（不接受邮政信箱）。
- **组织注册（若将来以公司名义）**：额外需要 **D-U-N-S 编号**、与企业域名一致的工作邮箱、可公开访问的企业官网。
- **公证**：会员资格包含公证服务，**不额外收费**；CI 侧用 App 专用密码 + Team ID 即可（本项目 `signing-notarization.md §2` 已写好完整流水线与 Secrets 清单，凭据注入即可生效）。
- **本项目现状**：**0.1.0 不发布 macOS 版**；等你决定做 macOS 版时再办（办证 + 出包 + 真机验证，预计 1–2 周）。

## 4. Linux：已经免费搞定

- Linux 没有 Windows/macOS 那种系统级「未知发布者」拦截；防篡改靠**校验和 + GPG 签名**。
- 本项目已交付 `scripts/sign-linux-artifacts.sh`（分离签名 + `SHA256SUMS` + `.asc`），并已实测「签名 → 校验 → 篡改检测」全通过。
- **唯一待办**：生成**正式发布 GPG 密钥**（建议离线主钥 + CI 用签名子钥）→ 注入 Secrets `LINUX_GPG_PRIVATE_KEY` / `LINUX_GPG_PASSPHRASE` → 把公钥指纹写进用户指南供用户核对。**0 元**。
