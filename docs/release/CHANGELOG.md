## [0.1.0] - 2026-09-22

首个公开版本：隐私与安全优先、数据完全本地化的加密资产组合追踪桌面应用。**本版发布 Windows 10/11 x64 与 Linux x64 两个平台**；macOS 版待代码签名证书与 Apple 公证就绪后随后续版本提供。
没有云端账号、没有遥测、没有在线同步——账本、密钥与流水全部留在你自己的机器上。

### 新增

- 支持创建本地账户并用密码登录；账户数据只保存在本机加密数据库中，不依赖任何云端账号。
- 支持「记住我」：登录令牌存入操作系统钥匙串（不可用时降级为本机 0600 权限文件），登出、切换账户或改密后立即失效。
- 支持多账户创建、切换与登出；切换账户须重新输入目标账户密码，账户之间数据互相隔离。
- 支持修改密码：只重新包裹数据密钥、不重新加密全部数据，历史备份文件不受影响；改密后需重新登录。
- 提供忘记密码说明：本机没有后门、也没有云端找回途径，忘记密码即无法解密该账户数据。
- 提供首次启动初始化向导：手动录入、CSV 导入、关联交易所只读 API（推荐）、从备份恢复四条路径，也可选择「稍后再说」。
- 提供仪表盘：净值、24 小时盈亏、ROI、投入本金（净）、可用现金、总收益、累计已实现盈亏与资产分布环形图。
- 提供资产列表：持仓七列（币种/数量/平均成本/当前价/总市值/浮动盈亏/累计已实现）均可排序，异常与估算状态以文字徽标标注。
- 提供币种资产详情：汇总指标、交易记录（交易所/类型/时间/搜索四维筛选）、持仓校准入口与校准历史。
- 提供交易管理页：手动新增、编辑、删除交易，实时总价，手续费自动计算（交易所费率优先于全局费率；手续费可选计价币、基础币或自定义币种）。
- 提供 CSV 导入：模板下载、逐行校验、影响摘要预览（新增/疑似重复/未解析/格式错误）、歧义币种人工确认、导入后自动重算。
- 提供资金管理页：记录增资与撤资、编辑删除、按类型与时间范围筛选，并展示可用现金与投入本金。
- 支持持仓校准：按交易所只读余额把本地持仓对齐到真实数量，校准记录并入资金列表并在同步日志留痕；多来源或行情不可用时说明原因。
- 全部派生指标由账本全量重放实时推导、不在库中缓存结果：平均成本、浮动盈亏、逐笔已实现盈亏与 ROI 均由此得出。
- ROI 采用「总收益 ÷ 累计增资」口径，撤资不抵扣分母；累计增资为 0 时显示「--」而不是数字。
- 提供 CSV 明文导出（数据主权）：交易记录、资金流水、持仓汇总三类，可直接回导，且不含任何 API 密钥。
- 行情采用两级数据源：CoinGecko 为主源，配置 CoinMarketCap Key 后在其失败或缺失报价时自动兜底，主源恢复后自动回落。
- 价格快照按小时留存并长期降采样，支持历史区间回填，用于 24 小时盈亏与记录时折算价。
- 提供行情浏览页：只读自选列表（现价/数据源/更新时间）、搜索添加与移除、自选上限 50 个、页面可见期间按刷新频率自动轮询。
- 支持只读交易所 API 同步（Binance）：读取余额与成交记录，按「交易所 + 订单号」去重，逐交易对增量拉取，不覆盖手工录入的交易。
- 同步范围与调用量有预算控制：按余额与历史已同步交易对收敛范围，超出预算的排队到下一轮并在同步日志注明。
- 提供额度治理与限流退避：统计 CoinGecko 免费额度、达到 80% 自动降低刷新档位、遇限流按指数退避并提示可注册个人 Key。
- 提供 `.cpro` 备份文件：明文头部（格式版本、应用版本、导出时间、时间范围、各表条数，无需密码即可预览）+ AES-256-GCM 加密载荷。
- 备份文件密码由用户独立设置，不回填账户密码、不允许空密码。
- 支持两种恢复语义：增量合并（按记录标识与「交易所 + 订单号」去重，已存在则跳过）与全量覆盖（需二次确认）。
- 全量覆盖前自动生成一份以本次密码加密的临时备份，路径随恢复摘要返回。
- 恢复前展示备份摘要与合并预览（将新增/已存在跳过/缺失币种），恢复后自动全量重放并列出「持仓异常」币种。
- 备份按账户隔离，币种以稳定标识跨设备解析；交易所 API 密钥随备份导出、导入时用目标账户密钥重新加密；行情 Key 属设备级秘密，不进入备份包。
- 提供系统托盘：关窗最小化到托盘、托盘菜单（打开主界面 / 立即同步 / 退出）、后台同步完成与失败的桌面通知。
- 支持开机自启（默认关闭），并提供「最小化到托盘」「同步通知」「备份提醒」开关。
- 跟随系统代理：自动读取操作系统代理设置（没有则回退环境变量），所有对外请求统一经代理；状态栏显示「代理：系统代理」或「直连」，开关即时生效。
- 提供设置页八个分组：通用、网络、行情与同步、日志与诊断、手续费、API 管理、数据管理、关于。
- 后台常驻调度：按设定频率刷新行情、按同步间隔同步交易、定期轮转日志，并按 30 天规则提醒备份；窗口从托盘恢复时立即刷新一次行情。
- 提供基础法币、数值精度、盈亏配色、明暗主题与界面语言（中文 / English，切换即时生效并持久化）等偏好设置。
- 提供日志查看/导出与诊断报告生成：日志与同步记录按「最近 1 万条或 90 天」轮转，查看、导出与诊断内容都经过脱敏。
- 提供关于页：版本号、开发者信息、隐私政策链接、行情数据源说明与「无遥测」声明。
- 支持全键盘操作：Tab 顺序合理，交互件有可见焦点环与无障碍名称，表格表头排序、图例与持仓行都可用键盘抵达。
- 提供中文 / 英文双语界面，数值与时间格式随语言和系统时区变化，金额与盈亏强制显示正负号。
- 内嵌中文字体（Noto Sans SC / Noto Serif SC，另附 JetBrains Mono 等宽字体），不依赖系统字体，跨平台显示一致。
- 界面按内容区有效宽度自适应：窄窗表格整表横向滚动且不压缩换行、指标数字单行时自动缩字号、被截断内容悬停显示全值。
- 提供原生安装包：Windows `.msi`（默认装到 `C:\Program Files\WuZhuFolio`）与 `.exe`，Linux `.deb` / `.rpm` / `.AppImage`。
- 提供便携版（Windows `.zip` / Linux `.tar.gz`）：解压即用、不写注册表、数据仍保存在本机数据目录。
- 安装包内嵌裁剪后的私有 Java 运行时，目标机器无需预装 Java。

### 变更

- 可用现金口径收敛：默认只把 USDT 视为现金并按 1:1 锚定折算；其他稳定币可在设置中自行增删，并按实时市价折算。
- 负持仓（通常来自导入账本缺少入金记录）的市值不再计入净值与可用现金，被排除的金额在仪表盘单独提示，币种行仍显示负值与「持仓异常」标记。
- 修正负持仓区间的成本口径：数量归零或转负时成本同步归零、穿越点按比例拆分，避免补录入金后平均成本与已实现盈亏被摊薄。
- 增资 / 撤资不再接受法币入账：法币请记录为兑换后实际到账的稳定币，界面会点名建议币种。
- 币种详情的交易记录新增「时间」筛选档位（全部时间 / 近 30 天 / 30–90 天 / 90 天以上），与交易所、类型、搜索叠加生效。
- 调整键盘焦点流：回车从侧边栏进入页面内容，页面内未被控件消费的 Esc / ↑ / ↓ 回到侧边栏当前项，侧边栏内可用 ↑ / ↓ 移动（弹层打开或组合键按下时不接管）。
- 统一设置页标题层级：分组一级 15/600、卡内二级 14/600、行标签 14/400、说明 11/400。
- 统一表格与卡片组件：表格列按最小宽度比例分配、单元格单行、补齐纵向列线、右侧留滚动条槽；卡片指标数字单行时自动缩字号；弹窗内容高度上限为窗口高度的 66%。
- 所有弹层改为同窗口内就地叠加并覆盖整页，不再撑开页面或出现错位。
- Windows 安装形态改为 per-machine 并关闭安装目录选择页（默认 `C:\Program Files\WuZhuFolio`）；从旧 per-user 安装升级需先卸载旧版。
- 「保存并首次同步」失败时的提示语义调整：API 密钥保存成功即关闭弹窗并刷新列表，同步失败以「已保存，但…（可重试）」提示，不再表现为保存失败。
- 行情页自选的开箱种子收敛为仅 USDT；搜索候选浮层在关键词清空或按 Esc 时自动收起。
- 状态栏的同步状态、行情数据源与额度信息改为读取真实数据源，不再使用占位文案。

### 安全

- 数据只存本机：账本、密钥与流水全部保存在本机数据目录（默认 `~/.wuzhufolio`），不上传任何云端；应用只与三个白名单主机通信（CoinGecko、CoinMarketCap、Binance）。
- 零遥测：不内置遥测、统计上报、崩溃上报或第三方分析 SDK，也不做自动更新检查；日志只有本机控制台与滚动文件两个输出，没有网络日志通道。
- 分层密钥：随机数据密钥（DEK）用于加密数据库与 API 密钥字段，账户密码经 Argon2id 派生的密钥（KEK）只用于包裹数据密钥；密钥材料只存在本机内存与操作系统钥匙串。
- 密码与登录凭据永不落盘：账户密码全程以字符数组处理，数据库只保存用于快速判错的校验值与包裹后的数据密钥；「记住我」令牌只写入操作系统钥匙串（不可用时降级为 0600 权限文件）。
- 整库加密：数据库由 SQLCipher 加密（AES-256、raw key 注入、每条连接都携带密钥）；错误密钥、旧明文库或损坏文件会被明确拒绝，不会静默继续。
- 字段级加密：交易所 API 密钥按「账户 + 条目 + 列」三重隔离的 AES-256-GCM 加密存储，界面只显示掩码，编辑时不回显明文。
- 备份包安全：`.cpro` 载荷为 AES-256-GCM，认证范围覆盖明文头部（改动头部即解密失败）；密码错误与文件损坏统一报同一个错误，不泄露旁路信息。
- 凭证不进备份与导出：行情 Key 为设备级秘密、不进入备份包；CSV 导出、日志导出与诊断报告都不含任何凭据。
- 日志与导出脱敏：日志在写入前统一经过脱敏处理（密钥形态与键值对打码），查看 / 导出日志与诊断报告时再次脱敏。
- 文件权限收紧：数据目录、日志目录与备份目录 0700；数据库（含 WAL/SHM）、密钥文件、备份文件、CSV 与日志导出、诊断报告 0600。
- 密钥生命周期管理：退出、登出、切换账户与改密都会擦除内存中的数据密钥；改密使用常量时间比较；派生参数低于 OWASP 基线（内存 <19 MiB 或迭代 <2）时拒绝装载。
- 账户隔离与守护测试：账户数据按账户过滤，跨账户恢复不会清空本地账户；行情与交易所两类客户端实例互相隔离，并有自动化守护测试防止回归。
- 仓库与产物不含凭据：源码仓库与构建产物中没有任何签名证书、API 密钥或个人凭据；签名凭据只经 CI 加密变量注入，未配置时产出未签名产物。
- 出站面收敛：运行期抓包实证只有三个白名单主机，且源码中不存在 Socket / URLConnection / WebSocket 等其他网络原语。

### 已知限制

- **安装或解压路径含非 ASCII 字符时 Windows 版无法启动**：jpackage 原生启动器在安装路径含系统代码页无法表示的字符（如中文）时加载不到随包 JVM，表现为弹窗「Failed to launch JVM」且没有应用日志；属上游工具限制，不是本应用缺陷。缓解：安装包默认装到 `C:\Program Files\WuZhuFolio`（纯 ASCII）且不提供目录选择页；需要自定义位置或无管理员权限时请用便携版，并把程序解压到纯英文路径。
- **备份文件密码无法找回**：`.cpro` 由密码派生的密钥加密，忘记密码即无法解密，本机没有后门。缓解：用密码管理器保存密码，并定期做一次恢复演练确认备份可用。
- **CoinMarketCap 兜底调用也计入 CoinGecko 额度账本**：同时配置两家 Key 时，CMC 的调用会抬高「CoinGecko 额度已用」百分比，可能提前触发 80% 降档（刷新频率降一档）。仅影响刷新节奏，不影响数据正确性与安全；已登记为后续版本改进项。
- **极低配机器上首次登录的密钥派生可能接近 2 秒**：派生参数按 OWASP 基线冻结（64 MiB / 3 次迭代 / 单线程），双核受限环境实测 173 毫秒；4 GB 双核真机尚未实测，若超过 2 秒预算，预案是下调到 OWASP 最低参数（19 MiB / 2 次迭代）。
- **读屏辅助技术的实测覆盖有限**：已完成 Windows 11 + NVDA 的基线走查并据此修复焦点问题，但 JAWS 等其他读屏软件与全部页面的组合尚未逐一实测；桌面端读屏支持弱于 Web 属所选技术栈的已知风险。
- **`.cpro` 采用非流式读写**：解码峰值内存随载荷增长（实测 20 万条记录约 483 MiB、70 万条约 1.4 GiB 堆）。常规规模余量充足；超大账本请提高堆上限，分块 / 流式化会改动文件格式与认证方式，留待后续版本评估。
- **不内置自动更新**（设计如此）：不会在后台检查或下载新版本，升级需到发布页手动下载新版；关于页只显示版本号与官方渠道链接。
- **Windows 采用 per-machine 安装**：安装与卸载需要管理员确认（UAC）；无管理员权限的用户请改用便携版，两种形态的数据位置一致。
- **Linux 的托盘与开机自启尚未在真机逐项实测**：Windows 11 侧已逐项走查通过；Linux 桌面托盘通常还需要 GNOME AppIndicator 扩展，无托盘宿主时应用降级为「关窗即退出」，而不是把窗口藏进不存在的托盘（降级分支已在无托盘宿主环境实证）。计划在发布后下载正式安装包在真机补测。
- **品牌标记以「同一枚标记、两种呈现」实现**：应用图标随安装包交付（Windows `.ico` 七档尺寸 / Linux `.png`，另备 macOS `.icns` 16–1024 供后续 macOS 版使用），托盘图标由同一枚标记（墨绿底 + 纸色 W 折线，色值取自产品设计令牌）在运行期程序化绘制——自带底色，在明暗两套系统托盘下均可见；两者是同一设计，不是占位图形。

### 未包含 / 后续版本

- 不含移动端（Android / iOS）应用，本版聚焦桌面端。
- 不含任何下单或交易执行能力：交易所 API 仅只读，行情页只做只读浏览，不含 K 线图与技术指标。

- 交易所适配目前仅 Binance，其他交易所留待后续版本。
- 未随本版提供 Linux Flatpak 包（当前提供 `.deb` / `.rpm` / `.AppImage` 与便携 tar.gz）。
- **未随本版提供 macOS 版**：需要 Developer ID 代码签名与 Apple 公证，证书采购完成并完成真机实测后随后续版本推出。
- **Windows 与 Linux 产物本版未做代码签名/GPG 签名**：Windows SmartScreen 首次下载可能提示「未知发布者」（选「更多信息 → 仍要运行」）；签名证书到位后自下一版本起签名（Linux 侧的 GPG 签名脚本已就绪）。
- 交易对级手续费率不在本版范围（费率按「交易所 > 全局」两级匹配）。
