## 一、评审结论

移动端 V1.1 停留在**桌面端 V1.2 时代**。桌面端 V1.3–V1.9 的跨端决策中，**法币方案（D6）、币种标识（D7）、行情数据规则（T2）、持仓校准（T1）、备份/加密/跨端 .cpro（N3 + T5–T7）五项全部未同步**；其余（遥测外部化、无障碍、交易所清单、打磨包）部分未同步或残留。数据模型仍以 `symbol` 字符串为主键，缺 `coins`/`exchange_coin_map`/`reconciliation_records` 表；`.cpro` 格式与桌面端**互不兼容**（V1.1 明示“暂不兼容”，现已过时且与跨端共享规范冲突）。

**结论：需发起移动端 V1.2 修订**，以《跨端共享规范》V1.0 为共同基准统一两端，同步桌面端 V1.3–V1.9 全部决策。

## 三、修订建议（移动端 V1.2 范围）

1. **顶部声明引用**：移动端 PRD 头新增“与桌面端共同引用《跨端共享规范》V1.0；冲突以共享规范为准”。
2. **全局说明对齐**：名词表、成本计算规范（含校准/重放/导入例外/折算解析）、法币角色、时间时区、行情规则、币种标识，改为**引用共享规范**或在移动端全文镜像，删除与本规范冲突的旧文本。
3. **数据模型对齐**：新增 `coins`、`exchange_coin_map`、`reconciliation_records`、`sync_logs` 表；`portfolio`/`transactions`/`fund_movements`/`price_snapshots` 升级 coin_id；`api_keys` 补 passphrase/extra；`accounts` 补 kdf_salt/kdf_params/wrapped_dek；`price_snapshots` 补 price_source。
4. **备份/加密对齐**：.cpro 格式、备份密码、合并/覆盖语义、加密边界按共享规范 §7/§8 重写；删除“跨端不兼容”声明。
5. **行情与设置对齐**：两级 Key 模式、5/15/30 刷新、额度治理、CMC 兜底；设置章补行情三设置项 + 默认精度 + 用户名枚举 + 备份提醒。
6. **其余**：成功指标注明外部度量方式；24h 缺价口径；无障碍基线；交易所收敛 Binance；残留清理（或兑换、BUSD）；打磨包。
7. **移动端 SRD 后续跟进**：PRD V1.2 定稿后，`移动端SRD.md` 的数据模型章节（第 14 章）需同步同一套表结构变更（coins/coin_id/reconciliation_records/.cpro 等）。
