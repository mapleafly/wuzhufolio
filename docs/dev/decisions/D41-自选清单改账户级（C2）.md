# D41 · 自选清单改账户级（**C2**，账户隔离）

> **决策号**：D41 · **日期**：2026-09-29 · **级别**：**C2**（人工拍板，命中 §8.1 红线：`§1.1-5` 多账户隔离 + 数据模型变更）
> **来源**：人工 2026-09-29 答复——「**行情清单应该是账户级的，不能是全局；这属于账户隔离问题**」
> **关联**：`docs/dev/0.1.1-使用反馈.md §7` · **D35**（成交币自动入自选）· `data-model.md` · `task-breakdown M14/T14.10`
> **状态**：✅ **已实施（2026-09-29）**——实现方案见 §3.0（**改为账户级 settings 行，不新建表**，理由见下）。

---

## 1. 背景（现状与问题）

自选（行情）清单当前持久化在 **`settings` 表的全局行** `watch.coins`（JSON 数组 `[cg_id]`，见
`domain/market/MarketWatch.kt:42`、`data/market/MarketWatchServices.kt:17`）——**与账户无关**。
叠加 **D35（成交币自动入自选）** 后后果明确：**A 账户交易过的币会被写进全局自选，B 账户登录后即可在行情页看到** ⇒
**跨账户可见性**，违反 `§1.1-5`「账户数据互相隔离」。

## 2. 拍板结论

**自选清单改为账户级**：每个账户拥有独立的、**有序**的自选清单；账户间互不可见；登出后不展示任何账户的自选。

## 3. 数据模型与迁移（§8.5 强制）

### 3.0 实现方案（**实施时收敛：账户级 settings 行，不新建表**）

决策档初稿拟新建 `account_watch_coin` 表；实施时发现 `settings` 表**本就有 `account_id` 列**
与 `UNIQUE(COALESCE(account_id,0), key)` 唯一索引，且 `.cpro` 备份**已覆盖账户级 settings**（ADR-005 §3）⇒
改用 **账户级 settings 行**（`settings(account_id=<id>, key='watch.coins')`，value 仍是 JSON 数组）：

| 维度 | 新表方案（初稿） | **账户级 settings 行（实采）** |
|---|---|---|
| 账户隔离 | ✅ | ✅ |
| 排序语义 | `position` 列 | ✅ JSON 数组序（与既有语义一致） |
| schema 变更 | 需新表 + 版本 +1 | **零**（复用既有列与唯一索引） |
| 备份兼容 | 需改表清单 + 版本 +1 | **零**（账户级 settings 已在备份范围内） |
| 代码面 | 新建表/仓库/DAO | 仅加 `SettingsRepository.getAccount/putAccount` 两个方法 |
| 后续扩展 | 便于加 per-coin 元数据 | 若将来需要（备注/分组），再迁移到独立表 |

⇒ 以「**账户隔离 + 排序 + 零 schema/备份变更**」为最优解，采账户级 settings 行。
`SettingsKeyNamespaceGuardTest` 同步扩展：`watch.coins` 登记为**账户级键**，并新增 `legacyGlobalKeys`
受控例外（历史全局行迁移期**只读**）；扫描规则新增 `getAccount/putAccount` 识别。

### 3.2 迁移（**无 schema 变更**；一次性认领）

1. **旧数据处置**：全局行 `settings.watch.coins` 无法归属到具体账户 ⇒ 迁移策略取
   **「首次登录时一次性认领」**：升级后第一个成功登录/恢复会话的账户，把旧全局清单**复制**为该账户的自选，
   并写入标记 `watch.migrated=1`（全局行保留只读，不再参与展示，便于回溯）；
   其余账户从**默认种子**（仅 USDT，2026-09-13 拍板口径）开始；
2. **不做破坏性删除**：旧 `settings.watch.coins` 行**保留**（标记为已迁移），避免"升级后数据消失"的观感；
3. **幂等**：迁移仅在 `watch.migrated` 未置位时执行一次。

### 3.3 备份兼容（`.cpro`）——**无需改动**

- 自选随**账户级 settings** 导出/恢复（备份本就把账户级 settings 纳入，ADR-005 §3）⇒ **备份格式与 schema 版本均不变**；
- **旧备份可恢复**：旧备份里没有账户级 `watch.coins` ⇒ 恢复后按 §3.2 的默认种子/认领逻辑处理（不报错）；
- **新备份在旧版本恢复**：旧版本会把账户级 `watch.coins` 当作"账户级 settings"正常写回（键名未变）⇒ 无兼容问题。
- **口径变更留痕**：D21 曾定「自选属展示偏好、不随备份导出」；D41 起自选为账户级偏好、**随账户备份导出**（本档修订 D21 该条）。
