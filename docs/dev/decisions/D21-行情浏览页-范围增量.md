## 1. 拍板结论

**V1.9 范围增补：正式「行情」页**（窄版 + 持久化自选），侧边栏第六个一级入口（仪表盘/资产列表/交易管理/资金管理/**行情**/设置）。

## 2. 页面定义

- **性质**：只读行情浏览（无交易、无图表/K 线/技术指标——维持 PRD Out of Scope「高级图表分析/交易」排除项）。
- **列表内容**：每行 = 币种（symbol + 名称）、现价、数据源（COINGECKO / COINMARKETCAP（兜底）/ 无行情 "--"）、更新时间。
- **币集合**：
  - 默认种子 = 稳定币白名单（USDT/USDC/DAI/TUSD，与 PortfolioCalculator.DEFAULT_CASH_COIN_IDS 同源）；
  - **持久化「我的自选」**：可增删，重启保留（settings 全局行 `watch.coins`，JSON 数组 [cg_id]，上限 50）；
  - 添加途径：输入框按 coins 目录搜索（复用 CoinCatalog.search，消歧口径同 M3），点候选加入自选；
  - 目录中已不存在的自选 cg_id 显示时跳过（解析期清理，不静默改写存储——后续目录恢复即重新出现）。
- **计价**：基础法币（settings.fiat 全局行，默认 USD；行情页仅显示该法币报价）。
- **刷新**：顶部「立即刷新行情」（复用 MarketRefreshService.refresh，币集 = 当前列表）；
  页面可见期间按行情刷新频率自动轮询（RefreshFrequency，额度 80% 降档语义随 refresh 结果提示——调度宿主归 M11）。
- **归属口径**：自选为**展示偏好**（与 theme/fiat 同层级全局设置，多账户共享；理由：非财务数据、同设备共享免重复维护——沿用 M002 全局设置先例；若后续要求按账户隔离再行决策）。
- **数据源**：price_snapshots.latest(coin, fiat)（M5 快照）+ coins 目录（symbol/name）；「无行情」= 快照无该 (coin,fiat) 行。
- **安全**：本页无 Key/无敏感输入；搜索只读目录。
