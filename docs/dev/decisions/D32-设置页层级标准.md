## 1. 背景

人工第五轮走查在设置页观察到三处层级不一致（`defects.md` DEF-24）：

1. **一级标题比二级还小**：分组标题「通用」「网络」「托盘与后台」… 用 `caption`（11sp/400/ink3），
   而其下二级标签（基础法币 / 主题 / 界面语言）用 `body`（14sp/400/ink）—— 视觉上级标题反而更弱；
2. **同级不同字号**：数据管理卡片标题（备份 / 恢复 / 明文导出）用 `pageTitle`（20sp/600），
   而手续费卡片标题（全局默认费率 / 交易所费率）用 `bodyStrong`（14sp/600）—— 结构同级、字号差 6sp；
3. **加粗口径不一**：手续费卡片标题加粗、其它分组一级标题不加粗。

根因：设置页由多个模块的分组组件拼装（M10 设置页 + M9 数据管理 + M6/M7 手续费 + M5 行情与同步 + M6 API 管理），
**各组件自行挑选排版令牌**，`design-tokens.md §3` 也没有「区段标题」这一层，导致同一页出现三种「一级标题」。

## 2. 拍板结论

### 2.1 DEF-24 → **C1**：设置页层级标准（本决策档）

设置页（含其全部内嵌分组组件）**只允许四种标题取值**：

| 层级 | 用途 | 取值 | Compose 令牌 |
|------|------|------|--------------|
| L0 页面标题 | 「设置」页顶 | 20px / 600 / `ink` | `pageTitle` |
| **L1 分组一级标题** | 通用 / 网络 / 托盘与后台 / 行情与同步 / 日志与诊断 / 手续费 / API 管理 / 数据管理 / 关于 | **15px / 600 / `ink`** | **`sectionTitle`（本决策新增）** |
| **L2 卡内二级标题** | 数据管理：备份 / 恢复 / 明文导出；手续费：全局默认费率 / 交易所费率；API 管理：已保存密钥 / 最近同步记录；行情与同步：子段标题 | **14px / 600 / `ink`** | `bodyStrong` |
| L3 行标签 | 基础法币 / 主题 / 界面语言 / 精度 … | 14px / 400 / `ink` | `body` |
| 辅助说明 | 行描述、hint、时间戳 | 11px / 400 / `ink3` | `caption` |

**禁止**在分组组件里另取字号表达「标题」（此前 `caption`/`pageTitle`/`bodyStrong` 三种并存即由此而来）。
