## 1. 本次改了什么（实现摘要）

### T10.1 settings/fee_rules（domain 契约 + data 实现 + 白名单生效接线）

- **GeneralSettingsService**（domain/settings，契约 + 视图模型）：通用设置用例——`view()` +
  `setBaseFiat`（候选 USD/EUR/CNY，与原型下拉口径一致）/ `setPrecision`（8/2/2 默认｜2/2/2）/
  `setUsernameEnum`（默认 on）/ `addCashCoin` / `removeCashCoin` / `setSmallAmountThreshold`
  （$1,000/$2,000/$4,000/$10,000，默认 $4,000）/ `setProxyEnabled`（默认 on）。
  实现 = `DefaultGeneralSettingsService`（settings 全局行读写；键：`fiat`〔与 M7/M8 折算链既有键
  同源〕、`display.precision`、`login.username.enum`〔M2 起登录页读取〕、`cash.coins`、
  `small.threshold`、`network.proxy.enabled`）。**账户级设置**自 M9 起由 BackupSettingsStore 承载
  （backup.last_at/restore.last_at，随 .cpro 导出）；PRD 7.2-6.1 各项为设备级偏好，存全局行
  （口径见 domain/settings/GeneralSettings.kt 头注，api-contracts §3 M10 补录）。
- **稳定币白名单「生效」接线**（additive，默认行为与 M9 前完全一致）：`cash.coins` 仅存**用户扩展项**
  （默认白名单 tether/usd-coin/dai/true-usd 固定于引擎常量，PRD「查看并扩展」语义，扩展项可移除）；
  `TransactionEventBuilder` 与 `DefaultFundService` 各增可选 `cashCoinIds: () -> Set<String>` 注入
  （默认 = `PortfolioCalculator.DEFAULT_CASH_COIN_IDS`），扩展币种进入 **USD 锚定集合**与
  **资金总览「可用现金」**（测试覆盖：默认 700 → 扩展 BNB 后 1100 的端到端数值断言）。
- **费率 CRUD 扩展**（T10.1，M7 最小版升级）：`FeeRuleService` 新增 `saveExchangeEdit(id, exchange,
  buy, sell)`——按行 id 编辑；交易所名变更 = 旧键删除 + 新键落库（**fee_rules 备份去重键
  account+exchange 联动迁移**，PRD 5.2-6 去重语义不变）；同键覆盖不新增行；全局行拒绝经此入口编辑、
  不存在的行类型化拒绝。UI 侧「编辑」按钮预填表单 → 「保存修改」/「取消」。

### T10.2 日志脱敏与轮转

- **LogRotationPolicy**（domain/redaction，纯规则）：本地日志与 sync_logs 各保留**最近 1 万条或
  90 天（先到为准）**（PRD §6 / interaction §2.6「日志轮转」行）；`keepLastLines` / `isExpired` /
  `cutoff`。
- **LogRotator**（data/logging）：启动执行一次（AppBootstrap）——活动 `*.log` 超上限原子重写保留
  最新段（临时文件+ATOMIC_MOVE）+ 早于 90 天的 `*.log`/`*.log.gz` 整档删除；logback `maxHistory`
  30→90 对齐（5MB 分卷为磁盘护栏，与 PRD 轮转正交）；摘要入日志（`log rotation ok | files: … |
  sync_logs removed byAge=N byCount=N`，GUI 冒烟已见该行）。
- **sync_logs 轮转**：`SyncLogRepository.rotate(now)`——先删早于 90 天的行，再裁剪到最新 1 万条
  （先到为准）；`countAll()` / `lastSyncAt()` 供诊断报告取数。
- **查看/导出脱敏**：`LogAccess` 契约（domain/settings）+ `FileLogAccess` 实现——查看尾部行与
  **导出文件均逐行经 LogRedactor 兜底**（写入侧已脱敏，双保险——PRD「导出日志含脱敏」验收口径）；
  导出 = 确认弹窗（PRD「导出日志前提示用户检查敏感信息」逐字文案）→ 系统保存对话框 → 原子写盘。

### T10.3 诊断报告

- **DiagnosticsService**（domain/settings 契约）+ `DefaultDiagnosticsService`（data/settings）：
  内容受限清单逐项（PRD §6）——应用版本（APP_VERSION 常量）/OS 版本/数据库 schema 版本（boot 迁移
  结果）/最近日志片段（尾部 100 行读取 + **生成时再脱敏一次**）/行情调用计数（SettingsQuotaLedger
  本月额度账本）/同步调用计数（sync_logs 累计条数 + 最近同步时刻——口径登记 §5-4）。
  **结构上不含密钥与完整响应体**（无任何读取路径）。`DiagnosticsReportText.render` 纯渲染，预览
  与导出文件同源；UI = 生成 → 预览弹窗 → 「保存到文件」。
