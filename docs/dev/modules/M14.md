## 4. 遗留问题

1. `WzSelect` 的**触发框**仍是自绘（内部已是 M3 `DropdownMenu`），换 `ExposedDropdownMenuBox` 待下批（需 `@OptIn`，并逐页回归）。
2. `WzToast` 与 M3 `Snackbar` 尚未统一（3s 自动消失与位置口径需先定）。
3. `AdaptiveTable`（D33）保持自研（**M3/Jewel/Carbon/Fluent 均无数据表格**）；虚拟化性能未实测。
4. `compose.material3` DSL 访问器在 CMP 1.12 已弃用（配置期有既有 deprecation 警告，与本模块无关）→ 后续按 C0 改显式坐标
   `org.jetbrains.compose.material3:material3:1.9.0`（**勿用** CHANGELOG 里的 `1.12.0-alpha03`）。
5. M3 官方缺陷待实测：`CMP-10038`（UTC 以西月份标签错一月，Open）、`CMP-10319`（OpenGL 下 TimePicker 配色，Submitted）。
