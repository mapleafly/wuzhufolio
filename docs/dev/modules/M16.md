## 2. `T16.1` 实现摘要

### 2.1 缺口结论（**先取证**）

**macOS 复现 `DEF-64` 同型缺口 ＝ 是**（三处同型缺陷中的第三处）。代码证据（修复前）：

| 证据 | 位置 | 事实 |
|------|------|------|
| ① 通道判定不含 macOS | `tray/NoticeDelivery.kt:29`（修前） | `useInAppToast` = `contains("linux") \|\| contains("windows")` ⇒ macOS = `false` |
| ② 渲染受 ① 门控 | `AppHost.kt:268`（修前） | `if (inAppToast) { DesktopToastWindow(...) }` ⇒ macOS **永不组合**提示窗 |
| ③ 托盘动作只走 `showNotice` | `AppHost.kt:98-102`（修前） | `showNotice` **只设 `notice` 状态**，不投原生气泡 |
| ④ 调用点 | `AppHost.kt:126-130` / `:131` / `:138` / `:145-149` / `:150` / `:156` | 托盘手动动作（门禁 / 开始 / 结果）**全部**只经 `showNotice` |
| ⑤ 对照：调度事件有兜底 | `AppHost.kt:236-240`（修前） | 后台事件 `if (inAppToast) showNotice else trayHost?.notify(...)` ⇒ 该路在 macOS **有**投递 |

⇒ **macOS 上「托盘手动动作」的全部提示（含未登录「请先登录」）静默丢失**——与 `DEF-64` 修复前的 Windows 完全同型。
（`D51` 后 macOS 已进发布范围 ⇒ 属**发布前置**，非可选优化。）
