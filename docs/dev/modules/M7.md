### 7.1 崩溃类（阻断走查）

**问题 8：下载标准模板报 "cannot call invokeAndWait from the event dispatcher thread"，点确定后程序退出。**
- 根因：VM 的 downloadTemplate/pickAndParseCsv 在 scope.launch **之前**同步调用文件选择器 lambda；
  WzButton.onClick 运行于 AWT EDT，Main 的 FilePicker 用 EventQueue.invokeAndWait → EDT 上调用自身直接抛异常，
  异常冒泡到 Compose 全局处理导致进程退出。
- 修复：① VM 把文件选择调用移入 scope.launch（Dispatchers.Default）并捕获异常；② FilePicker 按当前线程分流
  （EventQueue.isDispatchThread() → 直接显示，否则 invokeAndWait）。
- 回归：csvFilePickerRunsOffEventDispatchThread / templateDownloadWritesFileAndToasts（断言非 EDT 线程 + 模板内容落盘 + toast）。

### 7.2 保存无反馈类（问题 3/5/6/10 —— 同一根因链）
