## 1. 本次改了什么（实现摘要）

### T2.1 账户创建/登录（M003 + AccountRepository + 用例）
- 迁移 M003 accounts（data-model §2.1 七字段：id PK 自增/username UNIQUE/password_hash/kdf_salt/kdf_params/wrapped_dek/created_at；schema v2→v3）。
- AccountRepository（经 DbGate 单写队列）：createWrapped 单写事务内「插入→用真实 id 计算 wrapped_dek（AAD=account_id+wrapped_dek）→回写→回读」（解决 AAD 依赖 id 的鸡生蛋）；UNIQUE(username) 冲突经异常链识别为 UsernameTakenException（**已上移至 domain.accounts**，UI 不依赖 data）。
- DefaultAccountService（契约 = api-contracts §3 AccountService；domain/accounts 定义接口与 DTO，data 实现）：创建=salt16B(hex 存 kdf_salt)+DEK+单次 Argon2id KEK→password_hash=SHA-256(KEK‖"verify")（KekVerify，ADR-002 §3 快速判错）+wrapped；登录=单次 KDF→快速判错→GCM 解包认证（密码错/用户不存在统一 A1，不暴露存在性）；DEK 仅驻 ActiveSessionStore（登出/切换/改密即擦）。**参数一致性修复**：kdf_params 落库值 = crypto.defaultParams 实际值（测试注入 OWASP 参数时不再错配，KDF 只派生一次）。

### T2.2 记住我/会话（KeyringRememberMeStore + 令牌语义）
- 令牌 = 随机 256-bit（CryptoService.newSessionToken），wrapped_dek_session = AES-GCM(DEK, key=token, AAD=account_id+"session")（KeyWrap.wrapForSession，M1 扩展）；单槽条目（service WuZhuFolio / account remember-me），值 = id|b64url(token)|wrapped；缺失 vs 不可用 = M1 同款探针口径；登出/未勾选登录/切换/改密 → clear（ADR-002 §3）；改密后会话签出回登录页（PRD 5.1-6，原型分歧点按 PRD 实现，见 §5）。
- 降级：主密钥后端为 FILE_FALLBACK 时，记住我随行降级 0600 remember-me.dat（RememberMeStoreFactory.open，日志提示）——本机无 Secret Service，功能可完整验收。
- restoreSession()（契约补充方法，api-contracts 未定义启动恢复 → M2 增补并在本文档/接口登记）；损坏/失效条目自动清除回登录。

### T2.3 切换账户（严格模式）与 T2.4 改密
- 切换：目标账户列表（账户菜单）→ 必须输目标密码（单次 KDF+解包认证）→ 通过后替换活动会话并**清除记住我条目**；错密码 = PasswordMismatch（「密码错误」）；数据加载异常 = A3 文案。
- 改密：验证原密码（A2「原密码不正确」）→ 新 salt+新 KEK → **重包同 DEK**（数据不重加密）→ 更新 accounts 凭证字段 → 清记住我 + 会话签出（UI 回登录页，toast 提示「请重新登录」）；历史备份不受影响（备份密码独立，M9 语义不变）。
- 服务层防御：再次校验口令门槛（WeakPasswordException）与用户名合法性（UI 预校验 + 服务层双保险）。

### T2.5 登录链路 UI（Compose，按原型逐页还原）
- ui/auth 新包：AuthCopy（逐字文案单源）、AuthGateViewModel（状态机 RESTORING/LOGIN/CREATE/WIZARD/FORGOT/SHELL + 弹窗状态）、GatePages（登录[记住我默认勾选/用户名枚举下拉或纯输入双形态/空密码校验/正在解密…]·创建[三错并行+强度条 弱中强 + hint]·向导四卡[手动/CSV/API(推荐)/备份 + 稍后再说]·忘记[A4 整段]）、AccountDialogs（风险确认硬门控[未勾选确认创建 disabled]·账户菜单·切换 380·改密 400 含 KEK hint 整段）、GateWidgets/AuthGate（安全提示/Toast/会话门控宿主）。
- MainShell 增 accountArea 槽（侧栏底部账户 Chip：头像+账户名+「切换账户 / 登出」）；ShellViewModel 增 initialPage（向导落点）；app 由 AuthGate 接线（Runtime.session 装配；登录页用户名枚举开关读全局设置 login.username.enum，默认开，设置 UI 归 M10）。
- 向导四方式按规格映射：手动/CSV→交易页、API/备份→设置页 + toast「该功能将在{模块}上线后开放」（占位不造假交互；M6/M7/M9 落地替换）；「稍后再说」→仪表盘。

## 4. 规格落档（M2 定稿契约，后续模块引用）

1. kdf_salt 存储形态 = 32 位小写 hex（16 字节盐）；kdf_params 沿用 M1 存储串；password_hash = SHA-256(KEK‖"verify") 64hex（不落第二趟 KDF）。
2. wrapped_dek / wrapped_dek_session AAD 均以 accounts.id 十进制字符串为 account_id。
3. 记住我命名：KeychainAccounts.SERVICE + account "remember-me"（探针 "remember-me.probe"）；降级文件 remember-me.dat(0600)。
4. 登录页用户名枚举开关键 login.username.enum（"on"/"off"，默认 on；M10 设置 UI）。
5. 契约偏差登记：AccountService 增 restoreSession()（api-contracts §3 无启动恢复签名）；UsernameTakenException 移入 domain.accounts（ui 不依赖 data 模块）。
6. 数据模型勘误：settings.account_id 实际迁移 M001 为 TEXT（值 = accounts.id 十进制串），data-model §2.3 记 Integer——口径以迁移为准（SQLite 弱类型，无断裂风险），后续表按 data-model 类型落 DDL。

## 5. 与原型差异（人工门裁决点）

1. 账户菜单 = 居中模态（原型侧栏锚点下拉）：功能等价（列表/切换/改密/登出），视觉走查差异记录，M12 可换下拉。
2. 改密成功 → 回登录页重登（PRD 5.1-6 文字口径）；原型仅 toast 停留主壳。
3. 用户名枚举=自定义列表弹层（非原生 select）；创建页用户名已存在/切换密码错误文案为 M2 定稿（原型缺）。
4. 向导四方式为占位跳转 + 模块预告 toast（真功能 M6/M7/M9 替换）。
5. 忘记密码页无恢复操作入口（纯告知，M9 落地恢复向导后评估加入口）。
6. 密码可见性「眼睛」未实现（原型与 token 均未定义，增强留 M12 拍板）。
