## 2. 逐条影响面扫描（预估；定级后逐处勾选回写）

### B1 演示数据 / 首次引导
- **设计侧**：`ia.md`（空态入口/引导）· `flows.md`（首次引导流程）· `interaction.md`（引导异常态：导入失败/取消/重复加载）· **prototype 不改**（D42 已退役）
- **技术侧**：复用既有备份 / CSV 导入路径（**不新增表**）；引导标记建议存**账户级 settings**（与 D41 口径一致）→ `data-model.md` 补注；若新增用例接口 → `api-contracts.md` 补录
- **验收标准**：进 `task-breakdown.md`（新增 **M15 / T15.x**），不得只写在模块记录
- **用户文档**：`user-guide.md` 增「示例数据」与**一键清空**路径
- **风险**：示例数据与真实账本混淆 → **必须显式标记 + 可一键清除**；文档与 UI 双提示

### B2 多账户可见性优化
- **设计侧**：`ia.md`（顶栏元素）· `interaction.md`（切换确认/提示文案）
- **技术侧**：`ui` 层 + `ShellViewModel`；无数据 / 接口变更
- **风险**：误触切换 → 需确认或二次点击；切换仍走**严格密码校验**（不得因便利弱化）

### B3 自选跨账户导入（**建议 C2**）
- **设计侧**：`interaction.md`（导入确认：来源账户 / 影响范围 / 可撤销性）· `ia.md`（入口位置）
- **技术侧**：复用 `SettingsRepository.getAccount/putAccount`（**零 schema 变更**）；「列出其它账户自选（只读摘要）+ 显式选择」新用例接口 → `api-contracts.md` 补录
- **安全面（红线复核）**：`security-checklist.md §5` 复核「跨账户显式导入不破坏隔离判定」；新增守护测试（未登录不可导入 / 仅影响当前账户 / **不复制任何交易数据**）
- **数据与备份**：schema 与 `.cpro` 格式**不变** ⇒ `rollback.md` 无需新增口径
- **越界警示**：实现中出现「隐式跨账户可见」或「聚合视图」⇒ **升级重审**，不得夹带

### B4 设置页门禁收口
- **技术侧**：复用 `TrayActionGate.lockedNotice`（D43 已抽纯函数）；设置页同步入口改经调度器/门禁
- **测试侧**：守护测试扩至设置页入口（登录/未登录两态）
- **文档**：`interaction.md §1.6` 扩一句

### B5 工程项
- `ci.yml`（视觉回归 job：`VisualRegression` 产物比对）· `AGENTS.md`（埋点卫生条款 + **状态对齐 checklist**）· 可能新增 `scripts/visual-diff.mjs`
- **风险**：截图 diff 抖动容忍需先定（字体/GPU 差异）→ 建议先「存档 + 变化告警」，稳定后转阻断
- **⑤ 测试素材写回门控（F6）**：`ui/src/test/.../VisualRegression.kt:49-50` 把宣传素材写回 `docs/release/promo/assets/ui/`，
  全量测试即污染工作树且**跨平台字节不同** → 改 `build/` 或加 `-Pwuzhufolio.filmAssets=true` / env 门控（默认关闭）
