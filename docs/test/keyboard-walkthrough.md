# WuZhuFolio 纯键盘操作指南与走查脚本（keyboard-walkthrough.md）

> **用途**：① 说明本应用在桌面端的**键位语义**（与 Windows 原生应用不同之处）；② 提供一份**逐键走查脚本**，
> 用于判定「纯键盘不可用」到底是**用法问题**还是**缺陷**；③ 记录实测**焦点顺序**与失败取证方式。
> **适用版本**：**必须 `build=0.1.0+79d4069` 或更新**（`79d4069` 修复了「Tab 焦点链重复目标」缺陷 DEF-13）。
> 旧构建的典型症状见 §5「判定表」。
> **日期**：2026-09-15 · 依据：`docs/test/defects.md` DEF-13/DEF-14、`ui/KeyboardA11yUiTest`、`FundsPageUiTest::commandAreaIsReachableByKeyboardOnly`

## 1. 键位语义（先看这张表，能排除大半「不会用」）

| 键 | 作用 | 常见误解 |
|----|------|----------|
| **Tab** | 在**可聚焦控件**之间**向后**移动焦点 | 不是所有元素都能聚焦：**只读展示**（总览卡数字、环形图、表格文字、状态栏文字）**不参与 Tab** —— 它们由读屏的浏览模式朗读，不占 Tab 序 |
| **Shift+Tab** | 向前移动焦点 | — |
| **Enter** | 激活当前聚焦控件（按钮 / 侧边栏项 / 复选项）；在**输入框**里 = 提交（登录页、弹窗表单已支持，DEF-14） | 不是「打开菜单」的通用键 |
| **空格** | 同 Enter（按钮/复选项等价激活） | — |
| **↑ ↓ ← →** | **只在已展开的浮层内**移动选项（下拉候选、账户菜单、表格排序菜单） | ⚠️ **方向键不会在控件之间移动焦点**——这是 Compose Desktop 与 Windows 原生应用的**最大差异**。原生应用里「方向键在表单/页面间跳」在本应用**不成立**，必须用 Tab |
| **Esc** | 关闭当前弹窗/浮层（焦点回到触发它的控件） | — |
| **Alt / Ctrl 组合键** | 本应用**没有**全局功能快捷键（无 Alt+F 之类菜单键） | — |

> 换句话说：**纯键盘 = Tab 找控件 + Enter/空格激活 + Esc 退出 + 输入框内直接打字**，方向键只在浮层里用。

## 2. 前置检查（30 秒，先确认版本）

1. 打开应用后查看日志首行（Windows 路径：`%USERPROFILE%\.wuzhufolio\logs\wuzhufolio.log`）：

   ```
   bootstrap ok | build=0.1.0+79d4069 | db=…
   ```

   - `79d4069` 或更新 → 继续 §3；
   - `b1d2285` / `60599a8` → 含 DEF-13 修复，可用；
   - **无 `build=` 字段** → 是**早于 2026-09-15 的旧构建**，请重新下载安装后再测（旧构建确实存在「焦点进不了页面」缺陷）。

2. 界面语言设为中文（设置 → 通用 → 界面语言），避免干扰观察。

## 3. 实测焦点顺序（`79d4069`，Compose UI 测试实测）

进入主壳后，**每按一次 Tab 焦点前进一步**，顺序固定：

```
1  侧边栏：仪表盘       (nav-DASHBOARD)
2  侧边栏：资产列表     (nav-ASSETS)
3  侧边栏：交易管理     (nav-TRANSACTIONS)
4  侧边栏：资金管理     (nav-FUNDS)
5  侧边栏：行情         (nav-QUOTES)
6  侧边栏：设置         (nav-SETTINGS)
7  侧边栏：组件走查(DEV)(nav-GALLERY)
8  顶栏：刷新行情       (topbar-refresh-quotes)
9  顶栏：立即同步       (topbar-sync)
10 顶栏：主题切换 ☾     (theme-toggle)
11 页面内容第 1 个可聚焦控件（各页不同，见 §4）
12 页面内容第 2 个 …
…
然后回到第 1 项循环
```

> ⚠️ **重要预期**：侧边栏按 **Enter** 切页后，**焦点仍停在侧边栏**（不自动跳到页面里）。
> 因此从「资金管理」进入资金页后，要再按 **7 次左右 Tab** 才会落到页面第一个按钮（中间经过侧边栏其余项与顶栏）。
> 这是当前实现的焦点顺序，**不是键盘不可用**——但确实偏啰嗦（见 §6 改进提案）。

## 4. 逐键走查脚本（照着按，每步都有期望结果）

> 全程**不碰鼠标**。每步都写清「按什么 → 期望看到什么 → 不符合时的结论」。

### 步骤 1 · 登录（验证 DEF-14：回车提交）
1. 启动到登录页 → 按 **Tab**：焦点应在「用户名」输入框（有可见焦点框）；
2. 直接**打字**输入用户名（若为下拉枚举模式，用 **↓** 选账户后 **Enter**）；
3. 按 **Tab** → 焦点到「密码」→ 打字输入密码；
4. 按 **Enter** → **应直接登录**（按钮显示「正在解密…」）。
   - ❌ 若回车无反应：记下「步骤 1-4 回车无效」并截图（这是 DEF-14 回归）。

### 步骤 2 · 焦点环自检（30 秒判定新旧构建）
1. 进入主壳后，连按 **Tab 12 次**，每按一次看**焦点框在哪**；
2. ✅ **通过**：焦点能依次经过 侧边栏 7 项 → 顶栏 3 项 → **页面内控件**（如仪表盘的「刷新行情」按钮）；
3. ❌ **不通过（旧构建特征）**：焦点**只在侧边栏 7 项之间来回打转**，或每按两次 Tab 就有一次「焦点消失/看不出在哪」——请回到 §2 确认版本。

### 步骤 3 · 资金页：记录增资（本页已自动化实测可达）
1. **Tab** 到侧边栏「资金管理」→ 按 **Enter**（页面切换）；
2. 继续 **Tab**（预计 7 次内）直到焦点落到命令区按钮；继续 Tab 直到**「＋ 记录增资」**出现焦点框；
3. 按 **Enter** → 弹窗打开，**首输入框（币种）自动聚焦**；
4. 打字 `USDT` → 候选出现时按 **↓** 选择 → **Enter** 填入；
5. **Tab** 到「数量」→ 打字 `1000`；**Tab** 到「日期」（已预填当前时间，可跳过）；继续 **Tab** 到备注 → 可跳过；
6. **Tab** 到「保存」→ 按 **Enter** → 期望：弹窗关闭 + 右下角「已保存」提示 + 总览卡「可用现金」变化；
7. 按 **Esc**（若弹窗还开着）→ 期望关闭且焦点回到「记录增资」按钮。

### 步骤 4 · 交易页：手动买入（V5 校验）
1. **Tab** 到侧边栏「交易管理」→ **Enter**；
2. Tab 到「＋ 添加交易」→ **Enter**；
3. 首输入框（基础币）打 `BTC` → **↓/Enter** 选候选；**Tab** 计价币打 `USDT` → 选候选；
4. **Tab** 价格打 `50000`；**Tab** 数量打 `0.1`；**Tab** 手续费可留空；
5. 继续 Tab 到「保存」→ **Enter**：
   - 有本金 → 保存成功、列表出现新行；
   - 无本金 → 表单下方红字「USDT 余额不足，请先记录转入（增资）」（这是 V5 预期提示，不是键盘问题）。

### 步骤 5 · 仪表盘与刷新
1. **Tab** 到侧边栏「仪表盘」→ **Enter**；
2. Tab 到页面内「刷新行情」→ **Enter** → 期望：状态栏/按钮出现刷新中指示，价格更新；
   - 注：总览卡与环形图**不可聚焦**（只读展示），Tab 会跳过它们——这是预期。

### 步骤 6 · 设置与备份
1. **Tab** 到侧边栏「设置」→ **Enter**；
2. 页面很长：用 **Tab** 逐段前进（开关/下拉/按钮都会依次获得焦点），目标「备份」按钮；
3. **Enter** 打开备份弹窗 → 首输入框（备份密码）自动聚焦 → 打字（≥8 位含字母数字）→ **Tab** 确认密码 → 再打一次 → **Tab** 到「选择保存位置并生成」→ **Enter**；
4. 系统文件对话框弹出（**这是操作系统窗口，键盘用原生规则**：Tab/方向键+Enter 或直接输入路径）→ 确认保存；
5. 期望：右下角「备份完成：<路径>」。

### 步骤 7 · 退出弹窗与回焦点
1. 任意弹窗内按 **Esc** → 关闭；
2. 立刻按 **Tab** → 焦点应继续从**触发按钮之后**前进（不是跳回侧边栏）。

## 5. 判定表（走查后对照结论）

| 观察到的现象 | 结论 | 处理 |
|--------------|------|------|
| §2 日志无 `build=` 字段 或 `build` 早于 `b1d2285` | **旧构建**，DEF-13 未修 | 重新下载 CI 产物（见 §7）再测 |
| Tab 只在侧边栏打转 / 每隔一次「焦点消失」 | **缺陷**（DEF-13 回归或未生效） | 记录「页面名 + 第几次 Tab + 截图 + build 行」，报回 |
| Tab 能到页面按钮，但**要按很多次**才到（先走完侧边栏与顶栏） | **当前实现**，非缺陷（顺序啰嗦） | 见 §6 改进提案 |
| 只读卡片/图表不能被 Tab 选中 | **设计如此**（只读展示不参与 Tab 序） | 无需处理；读屏用浏览模式朗读 |
| 方向键在页面上无反应 | **设计如此**（Compose 不用方向键移动焦点） | 用 Tab；方向键只在浮层内用 |
| 输入框里回车不提交（登录/弹窗表单） | 登录页已修（DEF-14）；若**其它弹窗**表单回车不提交 | 记下具体弹窗，按 P8 体验项处理 |
| 弹窗内可以 Tab 但保存按钮按 Enter 无反应 | **缺陷** | 记录弹窗名 + 截图报回 |

## 6. 改进提案（需人工拍板，未实施）

**提案 A（推荐）· 进入页面后把焦点送进页面内容**：现在切页后焦点仍停在侧边栏，用户要再按约 7 次 Tab 才能进页面。
可在切页时把焦点移到页面容器（或页面内第一个可聚焦控件），实现「Enter 进页面 → 下一次 Enter 就能操作」。
影响面：`MainShell`（页面槽位加 `focusRequester`）+ `ShellViewModel`（切页事件驱动）；属**交互行为调整**，
按 `AGENTS.md §8` 需人工定级（建议 **C1**：新增焦点行为，不改数据/接口）。

**提案 B · 全局快捷键**：如 `Ctrl+1..6` 切页、`F5` 刷新行情、`Ctrl+B` 备份。PRD 未要求，建议 P8 评估。
