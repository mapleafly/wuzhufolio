# WuZhuFolio 纯键盘操作指南与走查脚本（keyboard-walkthrough.md）

> **用途**：① 说明本应用在桌面端的**键位语义**（与 Windows 原生应用不同之处）；② 提供一份**逐键走查脚本**，
> 用于判定「纯键盘不可用」到底是**用法问题**还是**缺陷**；③ 记录实测**焦点顺序**与失败取证方式。
> **适用版本**：**必须 `build=0.1.0+<本轮提交>` 或更新**。本版落地两条焦点流改进（`defects.md` DEF-20/DEF-21）：
> ① 候选选中后焦点**留在表单里**（不再掉出弹窗）；② 回车选中侧边栏项 → 焦点**直接进入页面内容**，
> 页面内 Esc/↑/↓ 回到侧边栏；侧边栏内 ↑/↓ 上下移动。旧构建（`79d4069` 及更早）无 ①②，典型症状见 §5。
> **日期**：2026-09-15（第四轮人工门后更新）· 依据：`docs/test/defects.md` DEF-13/DEF-14/DEF-20/DEF-21、
> `ui/KeyboardA11yUiTest`、`ui/shell/ShellFocusFlowUiTest`、`FundsPageUiTest::commandAreaIsReachableByKeyboardOnly`

## 1. 键位语义（先看这张表，能排除大半「不会用」）

| 键 | 作用 | 常见误解 |
|----|------|----------|
| **Tab** | 在**可聚焦控件**之间**向后**移动焦点 | 不是所有元素都能聚焦：**只读展示**（总览卡数字、环形图、表格文字、状态栏文字）**不参与 Tab** —— 它们由读屏的浏览模式朗读，不占 Tab 序 |
| **Shift+Tab** | 向前移动焦点 | — |
| **Enter** | 激活当前聚焦控件（按钮 / 侧边栏项 / 复选项）；**在侧边栏项上 = 切页并把焦点送进页面内容**（本版新增）；在**输入框**里 = 提交（登录页、弹窗表单已支持，DEF-14） | 不是「打开菜单」的通用键 |
| **空格** | 同 Enter（按钮/复选项等价激活） | — |
| **↑ ↓ ← →** | ① **侧边栏内** ↑/↓ 在导航项之间移动焦点（本版新增）；② **页面内容内**未被控件消费的 ↑/↓ 把焦点**交回侧边栏当前项**（本版新增）；③ 已展开浮层内移动选项（下拉候选、账户菜单、表格排序菜单） | ⚠️ 方向键**仍不会在页面内的控件之间**移动焦点（Compose Desktop 与 Windows 原生应用的最大差异）：表单里跳字段请用 Tab。输入框里的 ↑/↓ 是光标/候选行为，不会被外壳接管 |
| **Esc** | ① 关闭当前弹窗/浮层（焦点回到触发它的控件）；② **页面内容内**（无弹层时）把焦点交回侧边栏当前项（本版新增） | — |
| **Alt / Ctrl 组合键** | 本应用**没有**全局功能快捷键（无 Alt+F 之类菜单键） | — |

> 换句话说：**纯键盘 = 外壳内用 ↑/↓ 或 Tab 找入口 + Enter 进页面/激活 + Esc 或 ↑/↓ 回外壳 + 输入框内直接打字**；
> 表单**字段之间**仍用 Tab（方向键只在浮层与侧边栏里移动选项/焦点）。

## 3. 实测焦点顺序（`79d4069`，Compose UI 测试实测）

进入主壳后，**每按一次 Tab 焦点前进一步**，顺序固定：

```
1  侧边栏：仪表盘       (nav-DASHBOARD)
2  侧边栏：资产列表     (nav-ASSETS)
3  侧边栏：交易管理     (nav-TRANSACTIONS)
4  侧边栏：资金管理     (nav-FUNDS)
5  侧边栏：行情         (nav-QUOTES)
6  侧边栏：设置         (nav-SETTINGS)
7  侧边栏：组件走查(DEV)(nav-GALLERY)
8  顶栏：刷新行情       (topbar-refresh-quotes)
9  顶栏：立即同步       (topbar-sync)
10 顶栏：主题切换 ☾     (theme-toggle)
11 页面内容第 1 个可聚焦控件（各页不同，见 §4）
12 页面内容第 2 个 …
…
然后回到第 1 项循环
```

> ✅ **本版预期（重要）**：侧边栏按 **Enter** 切页后，**焦点直接落到页面内容里**（页面第一个可聚焦控件），
> 想操作页面按钮时**再按一次或两次 Tab/Enter 即可**，不必再穿过侧边栏余项与顶栏。
> 回到外壳：在页面内按 **Esc** 或 **↑/↓** → 焦点回到侧边栏当前页项（此后 ↑/↓ 可在导航项间移动、Tab 可到顶栏）。
> 若你的构建里「回车后焦点仍在侧边栏」，说明是本版之前的包，请按 §7 重新下载。
>
> 注：**仪表盘等以只读卡片/图表为主**的页面没有可聚焦控件，焦点请求无处可落 → 焦点会留在侧边栏（这是预期，不是缺陷；
> 只读内容由读屏浏览模式朗读）。

## 4. 逐键走查脚本（照着按，每步都有期望结果）

> 全程**不碰鼠标**。每步都写清「按什么 → 期望看到什么 → 不符合时的结论」。

### 步骤 1 · 登录（验证 DEF-14：回车提交）
1. 启动到登录页 → 按 **Tab**：焦点应在「用户名」输入框（有可见焦点框）；
2. 直接**打字**输入用户名（若为下拉枚举模式，用 **↓** 选账户后 **Enter**）；
3. 按 **Tab** → 焦点到「密码」→ 打字输入密码；
4. 按 **Enter** → **应直接登录**（按钮显示「正在解密…」）。
   - ❌ 若回车无反应：记下「步骤 1-4 回车无效」并截图（这是 DEF-14 回归）。

### 步骤 2 · 焦点环自检（30 秒判定新旧构建）
1. 进入主壳后，连按 **Tab 10 次**，每按一次看**焦点框在哪**；
2. ✅ **通过**：前 10 步依次是 **侧边栏 7 项**（仪表盘→资产列表→交易管理→资金管理→行情→设置→组件走查）→ **顶栏 3 项**（刷新行情→立即同步→主题切换），**每一步都有可见焦点框**；
3. ✅ **再验本版新增**：在侧边栏「资金管理」上按 **Enter** → 焦点框应**立刻出现在页面内的按钮上**（而不是还停在侧边栏）；
   接着按 **Esc** → 焦点框回到侧边栏「资金管理」；按 **↓** → 焦点框下移到「行情」；
4. ❌ **不通过（旧构建特征）**：焦点**只在侧边栏 7 项之间来回打转**、每按两次 Tab 就有一次「焦点消失/看不出在哪」、
   或回车切页后焦点仍停在侧边栏——请回到 §2 确认版本。

### 步骤 3 · 资金页：记录增资（本页已自动化实测可达）
1. **Tab** 到侧边栏「资金管理」→ 按 **Enter** → 期望：焦点**直接落到资金页内容区**（本版行为）；
2. 继续 **Tab** 直到**「＋ 记录增资」**出现焦点框（命令区就在页面顶部，通常 1–3 步内）；
3. 按 **Enter** → 弹窗打开，**首输入框（币种）自动聚焦**；
4. 打字 `USDT` → 候选出现 → **Tab** 到候选行 → **Enter** 选中 → 期望：**焦点落到「数量」输入框**（本版修复 DEF-20）；
5. 「数量」打字 `1000`；**Tab** 到「日期」（已预填当前时间，可跳过）；继续 **Tab** 到备注 → 可跳过；
6. **Tab** 到「保存」→ 按 **Enter** → 期望：弹窗关闭 + 右下角「已保存」提示 + 总览卡「可用现金」变化；
7. 按 **Esc**（若弹窗还开着）→ 期望关闭且焦点回到「记录增资」按钮。

### 步骤 4 · 交易页：手动买入（V5 校验）
1. **Tab** 到侧边栏「交易管理」→ **Enter**（焦点进页面内容）；
2. Tab 到「＋ 添加交易」→ **Enter**；
3. 首输入框（基础币）打 `BTC` → **Tab** 到候选行 → **Enter** → 期望：**焦点落到「计价币」**；计价币打 `USDT` → **Tab** 选候选 → **Enter** → 期望：**焦点落到「价格」**（本版修复 DEF-20，连续选候选不再掉焦点）；
4. 价格打 `50000`；**Tab** 数量打 `0.1`；**Tab** 手续费可留空；
5. 继续 Tab 到「保存」→ **Enter**：
   - 有本金 → 保存成功、列表出现新行；
   - 无本金 → 表单下方红字「USDT 余额不足，请先记录转入（增资）」（这是 V5 预期提示，不是键盘问题）。

### 步骤 5 · 仪表盘与刷新
1. **Tab** 到侧边栏「仪表盘」→ **Enter**；
   - 注：仪表盘以**只读卡片/环形图**为主，没有可聚焦控件 → 焦点**会留在侧边栏**（预期行为，不是缺陷）；
2. Tab 到页面内「刷新行情」→ **Enter** → 期望：状态栏/按钮出现刷新中指示，价格更新；
   - 注：总览卡与环形图**不可聚焦**（只读展示），Tab 会跳过它们——这是预期。

### 步骤 6 · 设置与备份
1. **Tab** 到侧边栏「设置」→ **Enter**；
2. 页面很长：用 **Tab** 逐段前进（开关/下拉/按钮都会依次获得焦点），目标「备份」按钮；
3. **Enter** 打开备份弹窗 → 首输入框（备份密码）自动聚焦 → 打字（≥8 位含字母数字）→ **Tab** 确认密码 → 再打一次 → **Tab** 到「选择保存位置并生成」→ **Enter**；
4. 系统文件对话框弹出（**这是操作系统窗口，键盘用原生规则**：Tab/方向键+Enter 或直接输入路径）→ 确认保存；
5. 期望：右下角「备份完成：<路径>」。

### 步骤 7 · 退出弹窗、退出页面与回焦点
1. 任意弹窗内按 **Esc** → 关闭（**弹层打开时外壳不接管 Esc/方向键**：先关弹层，不会把焦点甩到侧边栏背后）；
2. 立刻按 **Tab** → 焦点应继续从**触发按钮之后**前进（不是跳回侧边栏）；
3. 焦点在页面内容里按 **Esc**（或 **↑/↓**）→ 焦点回到侧边栏**当前页项**；再按 **↓** → 焦点下移到下一个导航项；
4. 从侧边栏按 **Tab** 继续 → 焦点依次经过侧边栏余项 → 顶栏 3 项 → 又回到页面内容（外壳循环完整）。

## 5. 判定表（走查后对照结论）

| 观察到的现象 | 结论 | 处理 |
|--------------|------|------|
| §2 日志无 `build=` 字段 或 `build` 早于 `b1d2285` | **旧构建**，DEF-13 未修 | 重新下载 CI 产物（见 §7）再测 |
| Tab 只在侧边栏打转 / 每隔一次「焦点消失」 | **缺陷**（DEF-13 回归或未生效） | 记录「页面名 + 第几次 Tab + 截图 + build 行」，报回 |
| 回车切页后焦点**仍停在侧边栏**（要按很多次 Tab 才进页面） | **旧构建**（本版已改：回车即进页面内容） | 按 §7 下载最新构建；若最新构建仍如此 → **缺陷**（DEF-21 回归） |
| 侧边栏按 ↑/↓ 不动焦点 | **旧构建**（本版新增侧边栏方向键） | 同上 |
| 页面内按 Esc/↑/↓ 焦点没回侧边栏 | **旧构建**（本版新增外壳退出键） | 同上；注意**弹层打开时**按键归弹层（预期） |
| 表单里选完候选后焦点「消失」、再按 Tab 从侧边栏重来 | **缺陷**（DEF-20 回归） | 记录「弹窗名 + 第几个候选 + 截图 + build 行」，报回 |
| 只读卡片/图表不能被 Tab 选中 | **设计如此**（只读展示不参与 Tab 序） | 无需处理；读屏用浏览模式朗读 |
| 方向键在页面**控件之间**无反应 | **设计如此**（Compose 不用方向键移动焦点） | 表单内用 Tab；方向键在侧边栏/浮层里移动选项/焦点 |
| 输入框里回车不提交（登录/弹窗表单） | 登录页已修（DEF-14）；若**其它弹窗**表单回车不提交 | 记下具体弹窗，按 P8 体验项处理 |
| 仪表盘上回车切页后焦点仍在侧边栏 | **设计如此**（该页无「页面内第一个可聚焦控件」，请求无处可落） | 无需处理；Tab 可到页面内的「刷新行情」按钮 |
| 弹窗内可以 Tab 但保存按钮按 Enter 无反应 | **缺陷** | 记录弹窗名 + 截图报回 |

## 6. 改进提案与落地状态

**提案 A ✅ 已落地（`defects.md` DEF-21，建议 C1 · 分级待人工拍板）**：切页时把焦点送进页面内容，并给出回外壳的出口。
实现：① 页面槽 `focusRequester`（挂非可聚焦容器 → 焦点落到子树内第一个可聚焦控件，回车进页面即可继续操作）；
② 页面内未被控件消费的 Esc/↑/↓ → 焦点回侧边栏当前项；③ 侧边栏内 ↑/↓ 移动。
护栏：弹层打开时外壳**不接管**（Esc/方向键归弹层）、带 Ctrl/Alt/Meta 的组合键不接管。
影响面：`MainShell.kt` + 新增 `ShellFocusNavigation.kt` + `WzModal.kt`（弹层计数）；**不改数据/接口/格式**。
人工拍板 C1 后按 `AGENTS.md §8.2` 补决策档 `D31-键盘焦点流.md` + 台账 + 下游回写；拍板 C0 则改记模块记录 §勘误。

**提案 B · 全局快捷键（仍待评估）**：如 `Ctrl+1..6` 切页、`F5` 刷新行情、`Ctrl+B` 备份。PRD 未要求，建议 P8 评估；
本版已把「带修饰键的组合键」从外壳焦点接管逻辑中排除，为将来快捷键留出通道。
