# M14 逐页视觉回归记录（T14.5，2026-09-29）

> 目的：M3 视觉规范落地（D38）后，把「逐页 × 主题 × 分辨率」的走查从**人工点一遍**变成**可复现的自动化渲染**，
> 人工只做目视复核与主观观感判断。

## 1. 方法（自动化部分）

- **工具**：`ui/src/test/kotlin/com/wuzhufolio/ui/regression/VisualRegression.kt`（测试内工具，复用各页既有 fakes）；
- **矩阵**：**4 个主页面 × 2 主题（明/暗）× 3 档窗口尺寸（1024×720 / 1280×800 / 1600×1000）= 24 张**；
- **渲染**：`runSkikoComposeUiTest(size = …)` 指定真实渲染尺寸（非裁剪）⇒ 截图即目标分辨率；
- **断言**：每张渲染都断言「页面根 + 关键元素已显示」（崩溃/关键元素缺失即测试红）；
- **产物**：`ui/build/visual-regression/<page>-<light|dark>-<WxH>.png`（构建产物，不入库）；
- **复现命令**：
  ```bash
  ./gradlew :ui:test --tests "*visual regression*"
  ```

| 项 | 原因 |
|---|---|
| 设置页（长页 + 多分组） | 需注入十余个服务 Fake，自动化成本高；其层级/字号口径已由 `SettingsPageUiTest` 断言守护 |
