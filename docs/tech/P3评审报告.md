## 三、发现项

### F1（重要，不阻断 P3 放行；P4/M5 开发前必须订正）

**`docs/tech/dev-setup.md` §4 与 ADR-002 §2.1 方案甲矛盾。**

- dev-setup §4 现文：「行情/交易所 API Key 在应用内设置页录入，**绝不入库、不入库、不入库**」。
- ADR-002 §2.1（2026-08-31 人工拍板方案甲）定稿口径：行情 Key 是应用级秘密，以**设备密钥加密后存 settings 表全局行**（key=market.coingecko_key / market.cmc_key）；不进 .cpro 备份、不用账户 DEK；OS 钥匙串存的是设备密钥，不是行情 Key 本身。
- 影响：dev-setup 是 P4/M5 开发者文档，现文会把 M5「行情 Key 设置 UI」引导到错误实现方向（且纯本地应用不落库也做不到加密持久化）。建议订正为：「录入 → 设备密钥加密 → 存 settings 全局行；不落明文、不进 .cpro 备份、不出设备」。

### N1（轻微）

dev-setup.md §1 工具链表内 Gradle 版本仍写 **8.14.3**（§6 与 wrapper.properties 均为 8.14.4），文档内部不一致。

### N2（轻微）

STATUS.md P3 产物清单描述 CI 为「createDistributable + packageUberJarForCurrentOS 冒烟」，与 ci.yml 现况不符——现仅冒烟 uber jar（注释说明 createDistributable 在 win/mac runner 不稳定、安装器打包留 P7，与 ADR-006 口径一致）。建议 STATUS 措辞同步。

### N3（轻微）

dev-setup.md §6 与 dependency-licenses.md §2b 有 `§BT§` 转义残留（反引号转义失败产物），影响观感不影响内容。

### N4（轻微，P4 卫生项）

两类编译警告（本地无缓存构建实证）：
1. `app/Main.kt:43` —— `ShellViewModel` 的 androidx.lifecycle.ViewModel 超类型跨模块可见（app 未直接依赖 lifecycle-viewmodel-compose，经 :ui 传递），建议 app 显式补依赖或 :ui 不对外暴露 ViewModel 类型；
2. `ui/ShellUiTest.kt` —— `runComposeUiTest` 已弃用（官方建议迁移 v2 API），4 处调用。
