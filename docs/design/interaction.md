## 1. PRD「统一异常处理」逐条映射

### 1.1 网络异常（PRD 条款：无法连接公共数据源或交易所 API）

| # | 触发条件 | 呈现位置 | 提示/文案 | 用户可操作 | 数据保留
|---|----------|----------|-----------|------------|----------|
| N1 | 行情源（CoinGecko/CMC）无法连接 | 状态栏（底部）+ 数据源徽章 | 红色断链图标 + “网络断开”；价格旁显示上次成功时间戳 | 点击图标手动刷新 | 保留上次成功数据 |
| N2 | 交易所 API 无法连接（同步失败） | 状态栏 + API 管理列表状态列 | “同步失败” + 具体原因（API 密钥失效/请求超限） | 点击手动同步；编辑密钥 | 保留本地账本 |
| N3 | 离线且需记录折算 | 表单内 + 指标旁 | “待定价” + “估算中” | 先保存，联网后自动回填重算 | 暂按最近可得价估算 |

> **代理状态指示（常态，非异常，PRD 4.2 验收 3 / 3.2 P0 需求）**：状态栏常驻「代理：系统代理」/「直连」文字指示（悬停提示「当前网络通过系统代理连接」）；网络异常时叠加 N1 断链图标。「设置 → 网络」提供系统代理开关（默认自动检测并使用操作系统代理，PRD 6.2），所有对外请求（行情/交易所 API）均经代理。

> 对应 PRD 原文：“在界面右上角或底部状态栏显示明显的‘网络断开’或‘同步失败’图标提示…保留上一次成功获取的数据。用户点击该图标可尝试手动刷新。具体 API 同步失败应有更详细的提示。”

### 1.2 后台服务异常（PRD 条款：数据文件损坏 / API 接口返回错误）

| # | 触发条件 | 呈现位置 | 提示/文案 | 用户可操作 |
|---|----------|----------|-----------|------------|
| B1 | 数据文件损坏或无法读取 | 全屏错误框 | “数据文件损坏或无法读取，请从备份恢复或联系技术支持” | 从备份恢复 |
| B2 | 交易所 API Key 失效 | 状态栏 + API 列表 + 同步结果 | “Binance API 密钥已失效，请检查或更新” | 编辑密钥重新验证 |
| B3 | 行情平台 Key 失效/额度耗尽（CoinGecko） | 状态栏 + 数据源徽章 | “CoinGecko 额度已达本月上限，已自动降频” | 配置/更换 Key；降频提示 |
| B4 | CoinGecko 共享限流（无 Key 模式） | 状态栏 + 数据源徽章 | “CoinGecko 共享限流触发，已自动退避；建议注册免费个人 Key 获取专属额度” | 注册并填写个人 Key |
| B5 | 兜底（CMC）失败 | 状态栏 | 保持上次价格 + 显示上次成功时间戳 | 手动刷新 |

> 对应 PRD 原文：“如遇数据文件损坏或无法读取等内部错误…引导用户从备份中恢复或联系技术支持。如果 API 接口返回错误…提供清晰的错误提示…而不是显示泛化的‘请求失败’。”

### 1.3 账户操作异常（PRD 条款：登录/改密/切换失败）

| # | 触发条件 | 呈现位置 | 提示/文案 | 安全要求 |
|---|----------|----------|-----------|----------|
| A1 | 登录失败 | 登录表单下方 | “用户名或密码错误” | 不暴露用户是否存在 |
| A2 | 改密原密码错误 | 改密弹窗 | “原密码不正确” | — |
| A3 | 切换账户加载失败 | 切换弹窗 | “账户数据加载失败，请重试” | — |
| A4 | 忘记密码 | 登录页入口弹层 | “本产品无法找回密码。若记得某次备份使用的密码，可通过该备份恢复数据；否则数据不可恢复。” | — |

> 对应 PRD 原文：“登录失败…密码错误…切换账户失败…应提供明确的提示信息，且不暴露具体错误细节（如用户不存在）。”

### 1.4 数据校验异常（PRD 条款：输入不符合规则）

| # | 字段 | 规则 | 呈现 |
|---|------|------|------|
| V1 | 价格/数量（交易） | > 0 的数字 | 输入框下方红色错误，阻止提交 |
| V2 | 手续费 | ≥ 0 的数字 | 输入框下方红色错误 |
| V3 | 手续费币种=自定义 | 必须填写币种代码 | 输入框下方红色错误 |
| V4 | 交易对/交易时间/必填项 | 非空 | 输入框下方红色错误 |
| V5 | 买入余额 | 计价币种持仓 ≥ 总价+计价手续费 | 表单下方“XX 余额不足，请先记录转入（增资）” |
| V6 | 增资/撤资数量 | 正数 | 输入框下方红色错误 |
| V7 | 撤资持仓 | 持仓 ≥ 撤资数量 | “XX 持仓不足，无法撤资” |
| V8 | 用户名/密码（创建） | 用户名非空且唯一、密码强度、两次一致 | 输入框下方红色错误 |
| V9 | 重放校验 | 编辑/删除导致任一时刻负持仓 | 阻止并提示冲突原因 |

> 对应 PRD 原文：“在输入框下方或附近显示红色错误提示，并阻止提交。”

## 2. 加载态 / 空态 / 错误态 / 离线态 / 限流态

### 2.1 加载态

| 场景 | 呈现 |
|------|------|
| 登录解密（Argon2id） | 登录按钮 loading + “正在解密…”，预算 ≤ 2 秒 |
| 行情刷新 | 价格旁轻微 loading 指示，不阻塞 UI（异步） |
| API 同步 | 状态栏“同步中” + 列表 loading；后台执行 |
| CSV 解析/导入 | 进度条 + 影响摘要预览 |
| 备份/恢复 | 进度条 |
| 列表滚动加载 | 底部 loading 占位 |

### 2.2 空态

| 场景 | 呈现 |
|------|------|
| 无持仓资产 | 占位图 + “暂无记录” |
| 无交易记录 | 占位图 + “暂无记录” |
| 无资金流水 | 占位图 + “暂无记录” |
| 无 API 密钥 | “尚未添加 API 密钥” + 添加引导 |
| 累计增资为 0 | ROI 显示“--” + “请先记录增资” |
| 24h 前价格全缺失 | 24h 盈亏显示“--” |

### 2.3 错误态 / 降级态

- 所有无数据字段统一显示“--”（PRD 列表默认数据规则）。
- 「无行情」币种不计入总资产市值，列表显示“无行情”。
- 24h 部分缺价：剔除缺失币种并标注“覆盖 N/M 个币种”；异源配对标注“混合数据源”。
- CMC 兜底期间：价格旁标注“数据源：CoinMarketCap”。

### 2.4 离线态

- 价格：保持上次价格 + 显示上次成功时间戳。
- 记录折算：标记“待定价”，暂按最近可得价估算并标“估算中”；联网后自动回填重算并消除标注。
- 校准：行情完全不可用时暂不允许执行并提示。

### 2.5 429 限流提示

| 模式 | 触发 | 呈现 |
|------|------|------|
| 无 Key（公共 API） | 429 频发 | “注册免费个人 Key 可获专属额度” |
| 已配置个人 Key | 月度额度达 80% | “CoinGecko 额度已达本月上限，已自动降频” + 自动降一档 |
| 兜底 CMC | 429 | 保持上次价格 + 时间戳 |

### 2.6 日志与诊断（PRD 6「日志管理与可追溯性」）

| 功能 | 入口 | 呈现与文案 | 约束 |
|------|------|-----------|------|
| 查看日志 | 设置 → 日志与诊断 | 日志列表（时间戳、操作类型、结果），见原型「日志（已脱敏）」弹窗 | 账户名与金额默认脱敏（部分遮蔽） |
| 导出日志 | 设置 → 日志与诊断 | 导出前提示「导出前请检查是否包含敏感信息」（已自动脱敏） | 密钥明文/哈希、完整 API 响应体禁止落日志 |
| 生成诊断报告 | 设置 → 日志与诊断 | 内容受限清单：应用/OS 版本、数据库 schema 版本、最近日志片段（已脱敏）、同步与行情调用计数 | 不含密钥与完整响应体 |
| 日志轮转 | 后台（无入口） | 本地日志与 sync_logs 各保留最近 1 万条或 90 天（先到为准） | 超出自动清理 |

## 3. 交互细节要点（汇总自 PRD 第 9 章）

1. 列表默认排序：资产按市值降序；交易记录按交易时间降序（最新在前）。
2. 列表滚动加载（资产、交易、资金、币种详情交易列表）。
3. 数值精度：金额/价格默认 8 位小数，市值/盈亏 2 位，百分比 2 位；微小价格自动增加有效位。
4. 盈亏数值强制显示 +/- 符号；颜色（绿涨红跌/红涨绿跌/蓝涨橙跌）仅作辅助语义。
5. 单击资产列表行 → 币种详情；饼图扇区点击 → 高亮 + 浮窗。
6. 删除交易/资金记录均需确认框；删除后触发全量重放重算且不可撤销。
7. API 保存后提示清理系统剪贴板；添加/编辑 API 提示关联当前账户。
8. 交易时间本地时区输入、UTC 存储；显示统一转本地时区。
9. 支持全键盘导航（Tab 焦点顺序、核心操作可达）+ 读屏可读文本标签。
10. 状态栏常驻代理指示（直连 / 系统代理，PRD 4.2 验收 3），见 §1.1 注。
11. 日志查看/导出与诊断报告入口在「设置 → 日志与诊断」，脱敏与轮转规则见 §2.6。
