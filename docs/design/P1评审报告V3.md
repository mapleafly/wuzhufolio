## 二、F1 登录链路实现明细（本轮核心交付）

原型新增「gate 全屏层」（覆盖主壳，状态机与 PRD 流程图 1 一致），含 4 个页面 + 全部交互态：

| 页面 | 核心元素（PRD 依据） | 交互（Playwright 验证） |
|------|---------------------|------------------------|
| **登录页** | 用户名下拉枚举（2 账户，枚举开关语义在 hint 注明）、密码、登录按钮、「记住我」默认勾选、「忘记密码」入口、「创建新账户」切换（PRD 9.1） | 空密码提交 -> 红色校验「请输入密码」阻止提交（V 类）；填密码 -> 按钮 loading「正在解密…」-> 进入主壳仪表盘；Enter 键提交 |
| **账户创建** | 用户名、密码（强度指示 3 段：弱/中/强）、确认密码、记住我（PRD 1.1） | 空提交 -> 3 处字段级红色错误（用户名空/密码强度/两次不一致）；合法输入 -> 弹出风险确认 |
| **风险确认弹层** | **PRD 逐字文案**：「密码是数据的唯一钥匙，本产品不上传也不存储密码，忘记密码将无法恢复任何数据；请妥善保管密码并定期备份」+「我已了解上述风险」勾选（PRD 1.1 验收硬条款） | 未勾选时「确认创建」**禁用**，勾选后启用 -> 进入初始化向导 |
| **初始化向导** | 欢迎语 + 四种方式（手动添加交易 / CSV 导入 / 关联交易所 API **推荐** / 从备份恢复）（PRD 流程图 1） | 四路径全部实测：手动 -> 交易表单；CSV -> 导入弹窗（含模板下载）；API -> 添加 API 弹窗 -> 保存 -> **立即执行首次同步**；备份恢复 -> 恢复弹窗（目标账户已创建/选定字段）；「稍后再说」-> 仪表盘 |
| **忘记密码** | **PRD 逐字文案**：「本产品无法找回密码。若记得某次备份使用的密码，可通过该备份恢复数据；否则数据不可恢复。」（故事 1.1） | 独立页面 + 返回登录链接 |
| **登出闭环** | 登出清会话令牌 -> 回登录页（故事 1.2） | 账户菜单「登出」-> gate 重新出现「登录」视图 |

附带补强：账户菜单「修改密码」由 toast 升级为完整弹窗（原密码 + 新密码二次确认 + 「仅重包 KEK / 历史备份不受影响 / 记住我令牌失效」语义，PRD 9.2）。
