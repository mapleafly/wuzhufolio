> P1 产物 · 桌面端 · 依据 `docs/prd/桌面端prd.md` V1.9 第 8 章功能流程图 + 第 9 章交互细节 + `跨端共享规范.md`。

## 1. 登录 / 记住我 / 账户创建

```mermaid
stateDiagram-v2
  [*] --> 启动
  启动 --> 有账户: 检测 accounts 非空
  启动 --> 创建向导: 无账户
  有账户 --> 登录页
  登录页 --> 记住我会话: 勾选记住我且钥匙串会话有效
  登录页 --> 密码校验: 输入用户名密码
  密码校验 --> 主壳: 校验通过
  密码校验 --> 登录页: 失败提示(用户名或密码错误)
  登录页 --> 忘记密码提示: 点击忘记密码
  创建向导 --> 风险确认: 填写用户名/密码/确认密码
  风险确认 --> 初始化向导: 勾选已了解风险并创建
  初始化向导 --> 主壳: 完成初始化
  记住我会话 --> 主壳
  主壳 --> 登录页: 登出(清会话令牌)
```

**关键规则**：
- 创建账户：密码强度校验（最小长度/含数字与字母）、二次确认、风险确认必须勾选（PRD 1.1）。
- 记住我：仅会话令牌入 OS 钥匙串，密码永不落盘；不勾选则每次启动重输密码。
- 忘记密码：提示“本产品无法找回密码，可通过记得密码的备份恢复”。
- 从备份恢复（全新安装入口）：恢复前先创建（或选定）目标账户，导入数据归入该账户（PRD 5.2-8、流程图 1）。
- 关联交易所 API（推荐）路径：密钥保存（测试请求验证通过并加密落库）后立即执行首次同步（PRD 流程图 3）。

## 2. 增资 / 撤资

```mermaid
stateDiagram-v2
  [*] --> 选择类型
  选择类型 --> 增资表单
  选择类型 --> 撤资表单
  增资表单 --> 校验
  撤资表单 --> 校验
  校验 --> 错误提示: 数量非正/币种空/日期空
  错误提示 --> 增资表单
  错误提示 --> 撤资表单
  校验 --> 撤资持仓检查: 类型=撤资
  校验 --> 保存: 类型=增资
  撤资持仓检查 --> 阻止保存: 持仓<撤资数量(提示XX持仓不足)
  撤资持仓检查 --> 保存: 持仓充足
  保存 --> 重放重算
  重放重算 --> 刷新列表与仪表盘
  刷新列表与仪表盘 --> [*]
```

**关键规则**：
- 币种基于 coins 目录自动补全+归一；输入法币代码提示改为记录兑换后到账的稳定币；默认取基础法币对应稳定币（USD→USDT，其余→USDC）。
- 折算基础法币金额按“记录时行情价”取数（本地快照优先 → 行情 API 回填）；离线标记「待定价/估算中」。
- 删除资金记录触发全量重放重算（确认框“将删除 N 条资金记录并重算投入本金与 ROI”）。

## 3. 交易（买入/卖出 + 手续费）

```mermaid
stateDiagram-v2
  [*] --> 交易表单
  交易表单 --> 实时计算: 输入价格/数量
  实时计算 --> 手续费: 手填 或 自动计算(交易所>全局费率)
  手续费 --> 保存点击
  保存点击 --> 数据校验
  数据校验 --> 字段错误: 价格/数量非正、必填缺失、手续费<0、自定义币种空
  字段错误 --> 交易表单
  数据校验 --> 买入余额校验: 类型=买入
  数据校验 --> 保存: 类型=卖出
  买入余额校验 --> 阻止保存: 计价币种持仓 < 总价+计价手续费(提示XX余额不足)
  买入余额校验 --> 保存: 余额充足
  保存 --> 重放重算
  重放重算 --> 刷新交易列表
  刷新交易列表 --> [*]
```

**关键规则**：
- 总价 = 价格 × 数量，实时显示；手续费币种（计价/基础/第三币种）决定联动扣减与成本计算口径。
- 买入：基础币种持仓增加（成本含手续费），计价币种持仓扣减（总价+以计价币种计的手续费）；卖出相反（总价−手续费）。
- 编辑历史记录触发重放校验：若重放任一时点持仓为负则阻止并提示冲突原因（如“该笔增资已被后续买入消耗…”）。

## 4. API 同步（交易数据）

```mermaid
stateDiagram-v2
  [*] --> 触发
  触发 --> 遍历密钥: 定时(默认30分) 或 手动同步
  遍历密钥 --> 请求交易所API
  请求交易所API --> 成功: 返回余额+最近成交
  请求交易所API --> 失败: 记录sync_logs+UI提示
  成功 --> 去重: 交易所+订单号
  去重 --> 写入新交易
  写入新交易 --> 遍历密钥: 下一个
  失败 --> 遍历密钥
  遍历密钥 --> 写sync_logs: 遍历完成
  写sync_logs --> 刷新交易列表与持仓
  刷新交易列表与持仓 --> [*]
```

**关键规则**：
- MVP 仅 Binance（api_key + secret_key，只读）；同步增量，不自动覆盖本地持仓余额。
- 交易所 API 仅返回最近 500 条成交，更早需 CSV 补录。
- 后台同步期间前台编辑入队等待并显示“同步中”（单写队列）。
- 保存 API 密钥（测试请求验证通过）后**立即执行首次同步**；保存后提示用户清理系统剪贴板（剪贴板历史云同步是真实泄露面，PRD 流程图 3 / 9.10）。

## 5. 行情数据刷新（CoinGecko → CoinMarketCap 兜底）

```mermaid
stateDiagram-v2
  [*] --> 触发: 定时(默认5分/窗口可见) 或 手动刷新
  触发 --> CoinGecko批量当前价
  CoinGecko批量当前价 --> 成功: 写快照 price_source=COINGECKO
  CoinGecko批量当前价 --> 失败判断
  失败判断 --> CMC兜底: 已配CMC Key 且 非币种未收录
  失败判断 --> 保持上次价格: 未配CMC Key / 币种未收录
  CMC兜底 --> CMC成功: 写快照 price_source=COINMARKETCAP 标注数据源
  CMC兜底 --> 保持上次价格: 失败
  成功 --> 更新估值与UI
  CMC成功 --> 更新估值与UI
  保持上次价格 --> 更新估值与UI: 显示上次成功时间戳
  更新估值与UI --> [*]
```

**关键规则**：
- 行情刷新与交易同步相互独立（各自定时任务/频率/日志）。
- 兜底仅在主源失败（网络/超时/429/额度耗尽/币种未收录）时启用；主源恢复自动回落。
- 无 Key 模式：429 指数退避+降频；429 频发提示注册个人 Key。配置个人 Key 后启用月度额度治理（80% 自动降一档）。

## 6. 持仓校准（单一数据来源）

```mermaid
stateDiagram-v2
  [*] --> 币种详情
  币种详情 --> 判定来源: 单一来源?
  判定来源 --> 隐藏入口并提示: 多来源(提示补录/增资撤资调整)
  判定来源 --> 显示校准按钮: 单一来源且交易所有余额
  显示校准按钮 --> 校验市价: 校准时市价可得?
  校验市价 --> 提示不可执行: 行情完全不可用
  校验市价 --> 生成校准记录: 差额=交易所余额-本地持仓
  生成校准记录 --> 差额账务: 正差按市价计成本入累计增资 / 负差按平均成本移出入累计撤资
  差额账务 --> 全量重放: 锚点语义
  全量重放 --> 刷新
  刷新 --> [*]
```

**关键规则**：
- 校准记录为锚点事件参与全量重放；锚点前历史编辑/删除不回滚校准效果。
- 差额视同系统生成资金操作，不产生盈亏，恒等式保持成立。
- 校准记录以“校准”类型进入资金管理列表，详情页可见校准历史。

## 7. 备份 / 恢复

```mermaid
stateDiagram-v2
  [*] --> 备份
  备份 --> 设密码: 默认填当前账户密码
  设密码 --> 敏感提示: 备份含API密钥
  敏感提示 --> 选路径
  选路径 --> 生成cpro: 明文头部+AES-256-GCM载荷
  生成cpro --> [*]
  [*] --> 恢复
  恢复 --> 选cpro
  选cpro --> 显示摘要: 明文头部(版本/时间/条数/范围)
  显示摘要 --> 输密码
  输密码 --> 校验: 通过?
  校验 --> 提示无效: 密码错误或文件损坏
  校验 --> 选方式: 通过
  选方式 --> 增量合并: 默认(uuid/订单号/模糊三级去重)
  选方式 --> 全量覆盖: 二次确认+自动临时备份
  增量合并 --> 重放重算
  全量覆盖 --> 重放重算
  重放重算 --> 刷新全部页面
  刷新全部页面 --> [*]
```

**关键规则**：
- 备份不含账户信息；备份密码独立于账户密码；跨设备/跨账户恢复只依赖备份文件密码。
- 明文导出（CSV：交易/资金流水/持仓汇总）不含 API 密钥。
- 全新安装（无账户）从初始化向导进入恢复：**先创建（或选定）目标账户**，导入数据归入该账户（PRD 5.2-8、流程图 1）；恢复只依赖备份文件密码，与原账户密码无关。

## 8. 切换账户 / 修改密码 / 登出

```mermaid
stateDiagram-v2
  [*] --> 账户菜单
  账户菜单 --> 切换: 列表选目标账户
  账户菜单 --> 改密: 原密码+新密码二次确认
  账户菜单 --> 登出: 清会话令牌
  切换 --> 输目标密码
  输目标密码 --> 验证
  验证 --> 锁定当前+解密新账户: 通过
  验证 --> 输目标密码: 失败提示
  锁定当前+解密新账户 --> 主壳
  改密 --> 重包KEK: 用新密码(数据不整体重加密)
  重包KEK --> 主壳
  登出 --> 登录页
```

**关键规则**：
- 严格模式：切换必须重新输入目标账户密码；无密码无法解密。
- 改密仅重新包裹 KEK，历史备份仍按导出时备份密码解密。

## 9. 全量重放（通用引擎，被 2/3/6/7 复用）

1. 输入：账户内 transactions + capital_flows + reconciliation_records，按时间升序。
2. 逐条推导每币种持仓与平均成本；校准记录作为锚点强制对齐。
3. 校验：手动路径负持仓即阻止；导入路径负持仓标记「持仓异常」。
4. 输出：持仓、累计增资/撤资、投入本金（净）、总收益、ROI、已实现盈亏。
5. 触发：任何历史记录新增/编辑/删除、校准、导入、恢复。
